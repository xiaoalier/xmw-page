# 课程网页生成规范（给生成用的子代理）

> 目标：为「信奥 C++ 星辰班」的**每一节课**生成一个**单文件、自带全部样式和脚本**的交互式 HTML，帮助学生复习和学习。
> 存放目录：`D:\student\课程网页\`
> 命名：`第NN课-课题.html`（NN 两位，如 `第02课-输入输出.html`）

## 一、风格样板（必须先看）
1. **必看**：`D:\student\课程网页\第01课-初入江湖.html` —— 这是**标准样板**，直接复用它的 CSS（`<style>` 整段）和整体结构。
2. 参考：`C:\Users\EDY\Documents\Default Project\初识循环3.html`、`循环嵌套.html`（老师原有网页，**只读，不要改动**）。
3. CSS 一律照抄样板（深色主题、卡片、面板、标签页、console、cell、quiz 等）。

## 二、每课必须包含的板块（顺序固定）
1. **页头**：`<h1>第NN课 · 课题</h1>` + 一句副标题
2. **知识点讲解**（1~3 节）：用 `nest-grid` 卡片 + `panel`；讲清「是什么 → 怎么用 → 例子 → ⚠易错」
3. **交互式"可视化器"**（**每课都要有**）：左边输入参数、点按钮，右边实时演示 / 画图 / 出结果，并生成"对应代码"（用 `lp-code`）
4. **C++ 代码**：`code-section` + 标签页（`code-tab` / `code-content`），3~5 个标签
5. **小测验**：**只做「选择题 + 判断题」**（见第三节）
6. **小贴士**：`tips-section`，5~8 条
7. 页脚：`信奥 C++ 星辰班 · 第NN课 课题`

## 三、小测验规则（重要）
- 题型**只有两种**：`choice`（选择题，4 个选项）、`judge`（判断题，对/错）。**不要填空题**。
- 题库 12~16 题，随机抽 8 题；每题必须有 `explain`（解析）。
- 交互：选择题点选项按钮、判断题点「✅ 对 / ❌ 错」按钮；答完显示解析、可下一题；最后给星级。
- **混入 GESP 真题**：尽量放 2~4 道**贴近该课知识点的 GESP 真题/改编题**（GESP 一级~四级，来源可参考 `D:\student\GESP考纲.md`、`D:\student\ACGO题单.md`、`D:\student\acgo_questions.json`）。
  - ⚠️ **只能引用你真实看到的题**；**没有把握的 GESP 原题一律不要编造**，可以写"GESP 风格题"或不标注来源。
- 复用样板里的测验引擎代码（`QUIZ_BANK` 的 `type` 字段用 `"choice"` / `"judge"`，`a` 选择题是正确选项下标、判断题是 `true/false`）。

## 四、硬性要求
- **单文件自包含**：所有 CSS/JS 都写在 HTML 里，不引用外部文件。
- **每课的可视化器必须真能用**（不是摆设）：点按钮要真的出结果。
- 代码块用样板的语法着色（`keyword/type/string/number/comment/function`）。
- 中文文案；用「可以」，不用「随时/任何/所有/立刻/马上」等绝对化词。
- 文件编码 **UTF-8**；生成后必须保证能被浏览器正常打开。
