1变量：给数据一个"名字"

变量是什么

变量就像一个带名字的盒子，用来存放数据。盒子有类型，整型的盒子只能放整数。

定义与初始化

int a; 是定义（先准备盒子）；int a = 10; 是初始化（准备盒子时先放一个 10）。

输入 cin

cin >> a; 从键盘读入一个数存进 a。尖尖朝右，表示数据"流进"变量。

📥怎么用：定义 → 输入 → 使用
// 1. 定义：告诉电脑"我要一个整型盒子叫 a"
int a;
// 2. 输入：把键盘敲进来的数放进盒子 a
cin >> a;
// 3. 使用：输出 a 里的值
cout << a << endl;

⚠ 易错：① 变量要先定义再使用；② cin 用两个大于号 >>，不是 <<；③ 输入多个数时中间用空格或回车隔开，例如 cin >> a >> b;。

2算术运算符：加减乘除取余

➗五个常用运算符
运算符含义例子（a=17, b=5）
+加17 + 5 = 22
-减17 - 5 = 12
*乘17 * 5 = 85
/除（整数相除只留整数部分）17 / 5 = 3
%取余（余数）17 % 5 = 2

⚠ 易错：两个整数相除，结果还是整数。5 / 2 的结果是 2 而不是 2.5；想得到余数要用 %，5 % 2 等于 1。注意 % 两边的数都必须是整数。

4C++ 里怎么写

读入两数求
定义与初始化

易错对比
// 读入两个整数，输出它们的和
#include <iostream>
using namespace std;

int main() {
    int a, b;                 // 定义两个整型变量
    cin >> a >> b;            // 从键盘读入 a、b
    int c = a + b;            // 算出新变量 c
    cout << c << endl;        // 输出结果
    return 0;
}

// 输入：3 4
// 输出：7
// 定义、赋值与初始化
#include <iostream>
using namespace std;

int main() {
    int a;            // 只定义，还没放值
    a = 10;           // 之后再赋值
    int b = 20;       // 定义时直接给初值：初始化
    int c = a + b;    // 用已有变量算出新变量
    cout << c << endl;
    return 0;
}

// 输出：30
// 整数除法与取余
#include <iostream>
using namespace std;

int main() {
    int a = 17, b = 5;
    cout << a / b << endl;   // 17 / 5 = 3（只留整数部分）
    cout << a % b << endl;   // 17 % 5 = 2（余数）
    return 0;
}

// 输出：
// 3
// 2
// 交换两个变量的值（借用临时变量 t）
#include <iostream>
using namespace std;

int main() {
    int a = 1, b = 2, t;
    t = a;      // 先把 a 存进 t
    a = b;      // 把 b 给 a
    b = t;      // 把原来的 a 给 b
    cout << a << " " << b << endl;
    return 0;
}

// 输出：2 1
// ❌ 变量没定义就直接用
a = 5;            // 报错：编译器不知道 a 是什么类型

// ❌ 输入方向写反
cin << a;         // 错误！cin 用 >>，数据流进变量

// ❌ 忘记分号
int a = 5         // 少了分号，报错

// ✅ 正确写法
int a = 5;
cin >> a;
cout << a + 1 << endl;

💡 小贴士

  • 输入用 cin，输出用 cout：cin >> a; 读入，cout << a; 输出，方向刚好相反。
  • 先定义后使用：int a; 之后再 cin >> a;，顺序不能颠倒。
  • 初始化是好事：int a = 0; 比只写 int a; 更安全。
  • 整数除法会"丢小数"：5 / 2 等于 2，5 % 2 才是余数 1。
  • 运算符优先级：先乘除取余，后加减；不确定就加括号。
  • 一次读多个数：cin >> a >> b;，输入时用空格或回车隔开。
