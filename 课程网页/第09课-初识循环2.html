1while 循环：条件成立就重复

是什么

只要条件成立，就一遍遍执行循环体；条件第一次就为假，则一次都不执行。

怎么用

while (条件) { 循环体; }，记得在循环体里改变循环变量，不然会停不下来。

执行顺序

先判断条件 → 真才执行循环体 → 再回来判断……直到条件为假。

🔁while 求 1 到 n 的和
int n, sum = 0;
cin >> n;
int i = 1;              // 循环变量要先赋初值
while (i <= n) {
    sum += i;
    i++;                  // 别忘了让 i 往前进
}
cout << sum << endl;

⚠ 易错：while 后面不写分号。写成 while (i <= n); 会变成空循环，可能一直转下去。

2do-while 循环：先做一遍，再判断

是什么

先执行一次循环体，再去判断条件。所以循环体至少执行一次。

怎么用

do { 循环体; } while (条件);，注意结尾 while(条件); 后面有分号。

适合场景

至少要运行一次，之后再看要不要继续，比如"先输入，判断输入是否合法"。

🔂do-while 结构（先做后判）
int i = 1;
do {
    cout << i << " ";
    i++;
} while (i <= 5);   // 这里的分号别漏
// 输出：1 2 3 4 5

💡 关键区别：while 先判断后执行，do-while 先执行后判断。条件一开始就为假时，while 执行 0 次，do-while 仍会执行 1 次。

while vs do-while
// while：条件成立就重复
#include <iostream>
using namespace std;

int main() {
    int i = 1;
    while (i <= 5) {
        cout << i << " ";
        i++;              // 改变循环变量，避免死循环
    }
    cout << endl;
    return 0;
}

// 输出：1 2 3 4 5
// while 累加：求 1 + 2 + ... + n
int n;
cin >> n;
int i = 1, sum = 0;
while (i <= n) {
    sum += i;
    i++;
}
cout << sum << endl;
// do-while：先做一遍，再判断
int i = 1;
do {
    cout << i << " ";
    i++;
} while (i <= 5);   // 结尾有分号
cout << endl;

// 输出：1 2 3 4 5
// 条件一上来就为假：while 一次不做，do-while 做一次
int i = 10;

while (i < 5) {
    cout << "while: " << i << endl;   // 不执行
}

int j = 10;
do {
    cout << "do-while: " << j << endl; // 执行一次，输出 10
    j++;
} while (j < 5);

💡 小贴士

  • while 先判断后执行：条件一开始为假，循环体一次都不执行
  • do-while 先执行后判断：循环体至少执行一次，结尾的 while(条件); 有分号
  • while 后面别加错分号：while (i <= n); 会让循环体空转，容易死循环
  • 循环变量要变化：循环体里写 i++ 或 i += ...，否则条件一直成立
  • 初值要先给：while / do-while 的循环变量要在循环前就定义好
  • for 与 while 可以互换：知道循环次数常用 for，次数不确定常用 while
