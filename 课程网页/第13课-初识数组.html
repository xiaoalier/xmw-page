1认识数组

什么是数组

数组就是一排连在一起的同类型格子。以前一个变量装一个数，现在一个数组能装很多个数，还各有各的编号。

int a[5];        // 5 个 int 格子
// 编号（下标）：0 1 2 3 4
下标从 0 开始

数组的第一格编号是 0，不是 1。所以 a[0] 是第一个，a[4] 是第 5 个。

a[0] = 10;   // 第 1 格
a[4] = 50;   // 第 5 格
常量定大小

数组大小常用常量 const int N = 100; 来定，这样以后想改大小，只改一处就行。

const int N = 100;
int a[N];    // 100 个格子

💡 一句话记住：数组 = 很多同类型格子 + 从 0 开始的编号。想用哪一格，就写 数组名[下标]。

2数组的注意事项

⚠ 下标从 0 开始

大小是 N 的数组，合法下标是 0 到 N-1。写 a[N] 就越界了。

int a[5];    // 合法下标 0~4
// a[5] ❌ 越界！
⚠ 不能整体赋值

数组不能像普通变量那样整体读写，要用循环一格一格地处理。

// int a[5], b[5];
// a = b;      ❌ 不能整体赋值
// cin >> a;   ❌ 不能整体读入
⚠ 大小要够用

数组开多大，就最多存多少个数。题目说最多 n 个数，数组一般开得比 n 大一点更保险。

const int N = 1005;   // 留点余量
int a[N];

// 数组的声明与初始化
#include <iostream>
using namespace std;

const int N = 5;      // 用常量定义大小

int main() {
    int a[N] = {10, 20, 30, 40, 50};
    cout << a[0] << endl;   // 10
    cout << a[4] << endl;   // 50
    return 0;
}
// 下标从 0 开始：第 1 个格子是 a[0]
#include <iostream>
using namespace std;

int main() {
    int a[3];
    a[0] = 11;   // 第 1 格
    a[1] = 22;   // 第 2 格
    a[2] = 33;   // 第 3 格

    cout << a[0] + a[2] << endl;  // 44
    return 0;
}
// 用循环一格一格读入
#include <iostream>
using namespace std;

const int N = 1005;
int a[N];

int main() {
    int n;
    cin >> n;
    for (int i = 0; i < n; i++) {
        cin >> a[i];       // 第 i 格
    }
    return 0;
}
// 用循环遍历输出
#include <iostream>
using namespace std;

const int N = 1005;
int a[N];

int main() {
    int n;
    cin >> n;
    for (int i = 0; i < n; i++) cin >> a[i];

    for (int i = 0; i < n; i++) {
        cout << a[i] << " ";
    }
    return 0;
}
// ❌ 常见错误 1：下标从 1 开始
int a[5];
a[1] = 10;   // 这其实是第 2 格，第 1 格 a[0] 还没赋值

// ❌ 常见错误 2：越界访问
int b[5];
b[5] = 1;    // 越界！合法下标只有 0~4

// ❌ 常见错误 3：整体赋值 / 整体读入
// int c[5], d[5];
// c = d;      不能整体赋值
// cin >> c;   不能整体读入，要用循环

// ✅ 正确：一格一格来
for (int i = 0; i < 5; i++) cin >> c[i];

💡 小贴士

  • 数组 = 一排同类型格子：一个数组能存很多个数，各有个编号
  • 下标从 0 开始：int a[5] 的合法下标是 0 1 2 3 4
  • 越界很危险：写 a[5] 或更大下标会访问到数组外面
  • 大小用常量：const int N = 1005; 以后改大小只改一处
  • 不能整体操作：读写数组都要用循环一格一格来
  • 数组通常开大一点：题目最多 n 个数，数组就开得比 n 稍大
