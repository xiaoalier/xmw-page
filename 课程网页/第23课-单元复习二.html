1第二单元知识地图

for 循环是骨架

已知次数的重复交给 for：初始化、条件、更新三件套。数组、字符串、二维数组的遍历都靠它。

数组是排好队的格子

一维数组 a[i] 存一排数，二维数组 a[i][j] 存一张表。下标都从 0 开始数。

字符与进制是细节功

字符数组靠 '\0' 收尾，字符串可以用 string；进制转换记住「除基取余，倒着读」。

// for 循环：求 1~n 的和
#include <iostream>
using namespace std;

int main() {
    int n, sum = 0;
    cin >> n;
    for (int i = 1; i <= n; i++) {
        sum += i;
    }
    cout << sum << endl;
    return 0;
}
// 一维数组：读入 n 个数，求最大值
#include <iostream>
using namespace std;
int a[105];

int main() {
    int n; cin >> n;
    for (int i = 0; i < n; i++) cin >> a[i];
    int mx = a[0];
    for (int i = 1; i < n; i++)
        if (a[i] > mx) mx = a[i];
    cout << mx << endl;
    return 0;
}
// 字符串：统计字母 'a' 出现的次数
#include <iostream>
#include <string>
using namespace std;

int main() {
    string s;
    cin >> s;
    int cnt = 0;
    for (int i = 0; i < (int)s.size(); i++)
        if (s[i] == 'a') cnt++;
    cout << cnt << endl;
    return 0;
}
// 进制转换：十进制 n 转二进制（除 2 取余，倒着读）
#include <iostream>
using namespace std;

int main() {
    int n; cin >> n;
    int box[40], top = 0;
    if (n == 0) { cout << 0; return 0; }
    while (n > 0) {
        box[top++] = n % 2;   // 取余数
        n /= 2;               // 除以基数
    }
    for (int i = top - 1; i >= 0; i--)
        cout << box[i];          // 倒着输出
    return 0;
}
// 二维数组：读入 n 行 m 列并求和
#include <iostream>
using namespace std;
int a[105][105];

int main() {
    int n, m, sum = 0;
    cin >> n >> m;
    for (int i = 0; i < n; i++)
        for (int j = 0; j < m; j++) {
            cin >> a[i][j];
            sum += a[i][j];
        }
    cout << sum << endl;
    return 0;
}

💡 小贴士

  • 下标从 0 开始：int a[5] 的合法下标是 0~4，访问 a[5] 就越界了
  • 数组要开够大：题目说 n 最多 100，就开 a[105] 留点余量
  • 字符数组结尾有 '\0'：char s[]="hi" 实际存了 3 个字符，最后一个是 '\0'
  • 字符串长度用 size()：s.size() 或 s.length()，遍历时用它做边界
  • 进制转换口诀：十进制转其它进制「除基取余、倒着读」；其它进制转十进制「按权展开相加」
  • 循环嵌套顺序：外层每变一次，内层完整跑一轮；先用外层选行，再用内层选列
  • 二维数组两个下标：a[i][j] 里 i 是行、j 是列，别写反
