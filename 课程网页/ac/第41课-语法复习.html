1最常见的几类语法错误

分号问题

语句结尾漏分号；for 括号里误加分号；结构体定义结尾漏分号。

括号与花括号

if/for/while 后面多写一个分号，导致循环体变成空语句。

类型与格式

整数除法丢小数、long long 没加、%d 配 long long。

数组越界

开小了数组、下标从 1 开始但只开了 n 个。

📌记住三个检查点

写完代码先扫三眼：分号齐不齐、花括号配不配对、数组开得够不够大。

2输入输出与运算的坑

📌常见写法
// 1. 一次读多个
int n; cin >> n;

// 2. 数字很大时用 long long
long long s = 0;
for (int i = 1; i <= n; i++) s += i;

// 3. 想要小数除法，先转 double
double avg = 1.0 * sum / n;

// 4. 多组数据：读到文件结束
while (cin >> n) { /* ... */ }

⚠ sum / n 是整数除法；1.0 * sum / n 才是小数除法。

6小贴士

💡 小贴士

  • 写完先扫一眼分号，尤其 for 和 if 后面。
  • 整数除法和小数除法要分清楚。
  • 数值可能很大时，求和先用 long long。
  • 数组多开 5 个位置，省得越界。
  • 多组数据的题，用 while (cin >> n) 读。
