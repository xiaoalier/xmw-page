1常用数学函数一览

要加头文件

这些函数都在数学库里，程序开头写 #include <cmath> 才能用。

开方与乘方

sqrt(x) 求平方根，pow(a, b) 求 a 的 b 次方。结果一般是小数（double）。

取整与绝对值

abs / fabs 求绝对值，ceil / floor / round 分别向上、向下、四舍五入取整。

3C++ 里怎么写

sqrt 求平方根
pow 求乘方
abs / fabs 绝对值
ceil / floor / round
综合：两点距离
// sqrt：求平方根，结果通常是小数
#include <iostream>
#include <cmath>
using namespace std;

int main() {
    double n = 16.0;
    cout << sqrt(n) << endl;   // 4
    cout << sqrt(2.0) << endl;  // 1.41421
    return 0;
}
// pow(a, b)：求 a 的 b 次方
#include <iostream>
#include <cmath>
using namespace std;

int main() {
    cout << pow(2, 10) << endl;   // 1024
    cout << pow(3, 3) << endl;    // 27
    // 想存成整数可以强转
    int v = (int)pow(2, 10);
    cout << v << endl;           // 1024
    return 0;
}
// abs 用于整数，fabs 用于小数
#include <iostream>
#include <cmath>
using namespace std;

int main() {
    int a = -5;
    double b = -3.5;
    cout << abs(a) << endl;    // 5
    cout << fabs(b) << endl;   // 3.5
    return 0;
}
// ceil 向上取整、floor 向下取整、round 四舍五入
#include <iostream>
#include <cmath>
using namespace std;

int main() {
    double x = 2.5;
    cout << ceil(x) << endl;    // 3（向上）
    cout << floor(x) << endl;   // 2（向下）
    cout << round(x) << endl;   // 3（四舍五入）
    return 0;
}
// 综合：求两点 (x1,y1) 与 (x2,y2) 的距离
#include <iostream>
#include <cmath>
#include <cstdio>
using namespace std;

int main() {
    double x1, y1, x2, y2;
    cin >> x1 >> y1 >> x2 >> y2;
    double dx = x2 - x1, dy = y2 - y1;
    double d = sqrt(pow(dx, 2) + pow(dy, 2));
    printf("%.2f\n", d);
    return 0;
}

💡 小贴士

  • 记得加头文件：用这些函数前写 #include <cmath>
  • sqrt 结果是小数：要整数可以用 (int)sqrt(n) 强转，或者用 round(sqrt(n))
  • abs 与 fabs 别混：整数用 abs，小数用 fabs
  • 三个取整分清楚：ceil 向上、floor 向下、round 四舍五入
  • 幂运算用 pow：pow(a, b) 就是 a 的 b 次方，结果为小数，必要时再转整数
  • 负数不能开平方：sqrt 的参数要保证不为负
  • max / min 比较两个数：max(a, b) 取大的，min(a, b) 取小的
