1字符变量 char

存放单个字符

char 用来存一个字符，用单引号括起来，比如 'A'、'b'、'7'。

本质是 ASCII 码

char 里存的其实是这个字符对应的整数（ASCII 码）。比如 'A' 存的是 65，'a' 是 97。

能和整数互转

因为本质是整数，所以 char 和 int 之间可以相互转换，比较大小也是比 ASCII 码。

🔤字符和它的 ASCII 码
char c = 'A';
cout << c << endl;          // 输出字符 A
cout << (int)c << endl;   // 输出 65（A 的 ASCII 码）

char d = 'A' + 1;       // 65 + 1 = 66，对应 'B'
cout << d << endl;          // 输出 B

💡 记住几个常见的：空格 32、'0' 是 48、'A' 是 65、'a' 是 97。

2字符数组和 '\0' 结束标志

一串字符存进数组

char s[100]; 能放 100 个字符，定义方式和普通数组一样，用下标访问每个字符。

末尾要有 '\0'

字符串末尾必须有一个 '\0'（空字符）作为结束标志，系统靠它判断字符串到哪里结束。

长度要多留 1 格

存 n 个字符的字符串，数组长度至少要 n+1，因为要留一个位置给 '\0'。

📦两种初始化方式
// 方式一：逐个字符赋值，系统不一定自动加 '\0'
char a[10] = {'h', 'e', 'l', 'l', 'o'};

// 方式二：用字符串常量赋值，系统自动在末尾补 '\0'
char b[10] = "hello";   // 末尾自动加 '\0'，一共占 6 格

⚠ 易错：如果忘了给 '\0' 留位置，或者覆盖了它，输出时就会接着往后面读，出现乱码。

3更方便的 string 类型

不用先定长度

string s; 直接就能用，不用像字符数组那样提前写死长度，长度会自己适应。

用 + 拼接、.length() 取长

string c = a + b; 用加号拼接；s.length() 得到字符个数（不含 '\0'）。

用下标取字符

s[i] 取出第 i 个字符，和字符数组一样从下标 0 开始，cin 输入也直接支持。

🧵string 的基本用法
#include <string>
string s = "hello";
cout << s.length() << endl;   // 5
cout << s[1] << endl;         // e（下标从 0 开始）

string a = "信奥", b = "C++";
cout << a + b << endl;        // 信奥C++

💡 string 和字符数组是不同的类型，用法相似但不能随便混用，转换要留意。

#include <iostream>
using namespace std;

int main() {
    char c = 'A';
    cout << c << endl;              // A
    cout << (int)c << endl;       // 65
    cout << (char)(c + 1) << endl; // B
    return 0;
}

char a[10] = {'h', 'e', 'l', 'l', 'o'};  // 逐个字符
char b[10] = "hello";                  // 字符串常量，自动补 '\0'

// b 在内存里：h e l l o \0
// 存 5 个字符，数组长度至少要 6
// 字符数组的输入与输出
char s[100];
cin >> s;              // 遇到空格或换行就停止；数组名不写 &
cout << s << endl;     // 输出整个字符串

// 想读一整行（含空格）可以用 getline
#include <string>
string line;
getline(cin, line);    // 读一整行，不含换行符
cout << line << endl;
// string 的常见操作
#include <iostream>
#include <string>
using namespace std;

int main() {
    string s = "hello";
    cout << s.length() << endl;  // 5
    cout << s[1] << endl;        // e

    string t = "CS";
    cout << t + "-plus" << endl; // CS-plus，用 + 拼接
    return 0;
}
// ❌ 错误 1：数组开小了，没给 '\0' 留位置
char s[5] = "hello";   // 实际需要 6 格（含 '\0'）

// ❌ 错误 2：单个字符用了双引号
char c = "A";            // 双引号是字符串，应该用 'A'

// ❌ 错误 3：cin 读数组名多写了 &
cin >> &s;              // 数组名本身就是地址，不用 &

// ✅ 正确
char s[10] = "hello";
char c = 'A';
cin >> s;

💡 小贴士

  • 单引号 vs 双引号：单个字符用 'A'，字符串用 "ABC"。
  • 字符串末尾有 '\0'：它是结束标志，不显示出来，但要占一格。
  • 长度多留 1：存 n 个字符，数组长度至少 n+1。
  • cin 读字符串不加 &：写成 cin >> s;，数组名本身就是地址。
  • cin 遇空格停：要读带空格的一整行，用 getline(cin, s);。
  • string 更省心：不用定长度，用 .length() 取长度、+ 拼接。
  • char 本质是整数：(int)'A' 是 65，能参与大小比较。
