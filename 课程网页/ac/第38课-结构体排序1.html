用 sort 配合自定义比较函数，把结构体数组排好序

1先回顾：sort 怎么用

📌sort 的基本用法
int a[5] = {3, 1, 4, 2, 5};
sort(a, a + 5);                 // 默认从小到大

// 想从大到小？加一个比较函数
bool cmp(int x, int y) { return x > y; }
sort(a, a + 5, cmp);

sort(起点, 终点后一位, 比较函数)。不写比较函数 = 升序；写了就按你的规则排。

2结构体排序：写一个 cmp

为什么不能直接 sort

结构体有很多成员，机不知道你要按哪个成员排，所以要自己告诉它。

cmp 怎么写

cmp(a, b) 返回 true 表示「a 应该排在 b 前面」。想降序就写 a.p > b.p。

⚠ 不能写 >=

cmp 必须满足「严格弱序」，用 >= 会导致排序结果错乱甚至崩溃。

📌按火力从高到低排
struct Ship { int id, power, armor; };
Ship s[100];

bool cmp(Ship a, Ship b) {
    return a.power > b.power;   // 火力大的在前
}
sort(s, s + n, cmp);

6小贴士

💡 小贴士

  • cmp 里返回 true 的意思是「第一个参数排在前面」。
  • 降序用 >，升序用 <；千万不要写 >= 或 <=。
  • sort 的第二个参数是「终点后一位」，写 s + n。
  • 比较函数写在 main 外面即可，参数类型要和元素类型一致。
  • 排完后，用 for 循环按顺序输出才是最终结果。
