1递归的两件事

终止条件

什么时候停下来？没有它就会无限调用，最后栈溢出。

递归关系

大问题怎么变成规模更小的同类问题，比如 n! = n × (n-1)!。

调用栈

每次调用都会压栈，一层层调用完再一层层返回。

📌阶乘：最经典的递归
int f(int n) {
    if (n == 1) return 1;      // 终止条件
    return n * f(n - 1);       // 递归关系
}

以 f(4) 为例：f(4)=4×f(3)=4×3×f(2)=4×3×2×f(1)=24，返回时一层层算回去。

2递归的执行过程

📌先「展开」，再「回来」
f(4)
 → 4 * f(3)
     → 4 * 3 * f(2)
         → 4 * 3 * 2 * f(1)
             → 1                    ← 到终止条件
         ← 4 * 3 * 2 * 1 = 24
     ← 4 * 3 * 2 = 24
 ← 24

6小贴士

💡 小贴士

  • 写递归先写终止条件，再写递归关系。
  • 终止条件要能真正被执行到（比如 f(1) 一定会到）。
  • 递归层数别太深，几百层以内一般安全。
  • 能用循环解决的简单问题，用循环也行。
  • 不确定递归对不对，就拿 n=1、2、3 手推一遍。
