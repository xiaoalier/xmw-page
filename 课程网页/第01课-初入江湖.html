1计算机小历史

从"算盘"到"电脑"

很久以前人们用算盘、机械齿轮来算数。后来出现了电子计算机，用电子信号计算，速度一下子快了无数倍。

冯·诺依曼结构

现代计算机的"总设计图"：运算器、控制器、存储器、输入、输出五大部件，程序和数据都放在存储器里。

编程语言

人说的话电脑听不懂，要用编程语言。C++ 就是其中一种，既能写游戏、也能打算法竞赛。

💡 记住一句话：程序 = 让计算机"一步步照做"的指令清单。我们写的每一行 C++，最后都会变成电脑能执行的命令。

2C++ 程序的基本框架

🏗背下这个"骨架"，每道题开头都长这样
// 1. 引入输入输出库（cout / cin 都在里面）
#include <iostream>

// 2. 使用标准命名空间（不然要写成 std::cout）
using namespace std;

// 3. 主函数：程序从这里开始执行
int main() {

    // 4. 你的代码写在这里
    cout << "Hello!" << endl;

    // 5. 正常结束，返回 0
    return 0;
}

五大件：引入头文件 → 命名空间 → int main() → 花括号 { } 里写代码 → return 0;。少一个都可能报错。

易错对比
// 最经典的第一个程序
#include <iostream>
using namespace std;

int main() {
    cout << "Hello, C++!" << endl;
    return 0;
}

// 输出：
// Hello, C++!
// 想输出几行，就写几条 cout
#include <iostream>
using namespace std;

int main() {
    cout << "第一行" << endl;
    cout << "第二行" << endl;
    cout << "第三行" << endl;
    return 0;
}

// 输出：
// 第一行
// 第二行
// 第三行
// 用输出画一个简单的图形
#include <iostream>
using namespace std;

int main() {
    cout << "  *  " << endl;
    cout << " *** " << endl;
    cout << "*****" << endl;
    return 0;
}

// 输出：
//   *
//  ***
// *****
// ❌ 常见错误 1：漏了分号
cout << "Hi" << endl      // 少了 ; → 报错

// ❌ 常见错误 2：漏了 #include
// 没有 #include <iostream> 就用 cout → 报错

// ❌ 常见错误 3：cout 里用了中文引号
cout << “Hello”;            // 中文引号 “ ” 不行，要用英文双引号 "

// ✅ 正确写法
cout << "Hi" << endl;
// ✅ 换行还可以用 "\n"（效果和 endl 一样）
cout << "Hi\n";

💡 小贴士

  • 程序框架要背熟：#include → using namespace std; → int main(){ ... return 0; }
  • cout 的箭头方向：数据"流进"屏幕，所以写成 cout << 内容;（尖尖朝左）
  • 每条语句以分号结束：; 是 C++ 语句的"句号"，漏了必报错
  • 换行两种写法：endl 或 "\n"，效果一样
  • 字符串要用英文双引号："你好" ✅；中文引号 “你好” ❌
  • 大小写敏感：cout 不能写成 Cout、main 不能写成 Main
