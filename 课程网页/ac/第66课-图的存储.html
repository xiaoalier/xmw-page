邻接矩阵和邻接表：两种存图方式

1邻接矩阵：开一张表

怎么存

g[u][v] = 1 表示 u 到 v 有边；带权就存权值。

优点

判断两点是否相邻 O(1)；写起来最简单。

缺点

空间 O(n²)，n 大了（1e5）就爆内存。

📌写法
int g[1005][1005];

// 加一条无向边
g[u][v] = 1;
g[v][u] = 1;

// 带权
g[u][v] = w;

⚠ 适合 n ≤ 1000 左右、边比较密的图。

2邻接表：每个点挂一个列表

📌vector 版本
vector<int> g[100005];

g[u].push_back(v);        // 有向边 u → v
g[v].push_back(u);        // 无向图再加反向

// 遍历 u 的所有邻居
for (int v : g[u]) cout << v << " ";

⚠ 空间 O(n + m)，n 到 1e5、1e6 都扛得住，比赛里最常用。

6小贴士

💡 小贴士

  • 小图（n≤1000）可以用邻接矩阵，写起来快。
  • 大图（1e5 以上）必须用邻接表。
  • 无向图两个方向都要加。
  • 带权图在边上存权值。
  • 邻接表遍历邻居就是遍历它的边。
