BFS：一层一层往外扩，第一次到达就是最短

1BFS 的思路

一层一层扩展

先处理距离为 1 的所有点，再处理距离为 2 的…

用队列实现

把待扩展的点放进队列，先进先出保证按层处理。

求最短路

边权都为 1 时，第一次到达某点的距离就是最短距离。

📌网格 BFS 框架
dist[sx][sy] = 0;
queue<pair<int,int>> q;
q.push({sx, sy});

while (!q.empty()) {
    auto [x, y] = q.front(); q.pop();
    for (四个方向) {
        int nx = x + dx[i], ny = y + dy[i];
        if (不能走 || 已访问) continue;
        dist[nx][ny] = dist[x][y] + 1;
        q.push({nx, ny});
    }
}

⚠ 入队时就设置距离并标记，不要等出队，否则会重复入队、甚至死循环。

2BFS 和 DFS 的区别

📌什么时候用谁
DFS：问「能不能到」「有几个连通块」「枚举所有方案」
BFS：问「最短几步」「最少几次操作」（边权相同）

⚠ 带权最短路（边权不同）要用 Dijkstra，BFS 不适用。

6小贴士

💡 小贴士

  • 入队就标记 + 设距离。
  • 边权相同时 BFS 求最短路。
  • dist 用 -1 表示未访问。
