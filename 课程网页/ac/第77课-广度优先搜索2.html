多源 BFS：从多个起点同时扩散

1多源 BFS

多个起点

比如地图上有好几个水源，同时向外扩散，问每个格子被淹的时间。

做法

一开始把所有起点都压进队列（距离 0），后面流程和普通 BFS 一样。

效果

一次 BFS 就能算出所有格子到「最近的起点」的距离。

📌框架
for (每个起点) { dist[sx][sy] = 0; q.push({sx, sy}); }

while (!q.empty()) {
    auto [x, y] = q.front(); q.pop();
    for (四个方向) {
        if (能走 && dist[nx][ny] == -1) {
            dist[nx][ny] = dist[x][y] + 1;
            q.push({nx, ny});
        }
    }
}

⚠ 关键是「所有起点先一起入队」，不是一个个单独跑 BFS——那样会慢很多。

2常见题型

📌多源扩散类
① 多个水源扩散，问最后被淹的位置/时间
② 多个出口，问每个点到最近出口的距离
③ 腐烂的橘子：每分钟向四周扩散

⚠ 这类题的答案往往是「dist 的最大值」或者「还有没有 -1 的格子」。

6小贴士

💡 小贴士

  • 多源 BFS：所有起点先入队。
  • 答案常是 dist 的最大值。
  • 要检查有没有到不了的格子。
  • 起点的 dist 设为 0。
  • 本质还是 BFS，按层扩展。
