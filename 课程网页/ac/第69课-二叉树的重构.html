1重构的原理

前序 + 中序

前序第一个一定是根；在中序里找到这个根，左边是左子树、右边是右子树，递归下去。

后序 + 中序

后序最后一个一定是根；同样在中序里切开，递归。

前序 + 后序不行

缺了中序，左右子树分不开，答案可能不唯一。

📌前序+中序 求后序
void build(string pre, string in) {
    if (pre.empty()) return;
    char root = pre[0];
    int k = in.find(root);           // 根在中序里的位置
    string lp = pre.substr(1, k);    // 左子树的前序
    string rp = pre.substr(k + 1);   // 右子树的前序
    string li = in.substr(0, k);     // 左子树的中序
    string ri = in.substr(k + 1);    // 右子树的中序
    build(lp, li);
    build(rp, ri);
    cout << root;                    // 后序：最后输出根
}

⚠ 关键是 `k = in.find(root)`，把中序切成左右两段。

2为什么要中序

📌中序提供左右边界

前序/后序只能告诉你「谁是根」，只有中序能告诉你「根左边是左子树、右边是右子树」。所以必须配中序。

6小贴士

💡 小贴士

  • 前序第一个、后序最后一个，都是根。
  • 必须配中序才能唯一还原。
  • 在中序里 find 根，左段是左子树。
  • 切分长度时左右要一致。
  • 空串立刻返回，是递归的终止条件。
