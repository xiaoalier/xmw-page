第06课 · 双分支结构

双分支 if-else + 逻辑运算符 && / || / ! 与短路 + 三目运算符

1双分支：if ... else ...

是什么

条件成立走一支，不成立走另一支。两条路必走一条，而且只走一条。

怎么用

if (条件) { ... } else { ... }，条件用一对圆括号，代码块用花括号。

常见场景

判断奇偶、正负、是否及格、两个数选较大者……都是"二选一"。

🔀一句话：二选一，条件为真走 if，为假走 else
int score = 75;
if (score >= 60) {
    cout << "及格" << endl;   // 条件为真，走这里
} else {
    cout << "不及格" << endl; // 条件为假，走这里
}
// 输出：及格

⚠ 易错：else 后面不写条件，也不要加分号。else; 会被当成一条空语句，后面的花括号就和 if 脱钩了。

2逻辑运算符：&& 、 || 、 ! 与短路

&&（并且）

两边都为真，整体才为真。只要有一个假，结果就是假。

||（或者）

只要有一边为真，整体就为真。两边都假才是假。

!（非）

把真假"反过来"：真变假，假变真。注意是英文感叹号。

🧠真值表（背下来，判断就不会错）
ABA && BA || B!A
假假假假真
假真假真真
真假假真假
真真真真假

🔎 短路特性：
· A && B：如果 A 已经是假，结果一定为假，B 就不会再计算；
· A || B：如果 A 已经是真，结果一定为真，B 就不会再计算。
这个"后面的不算了"就叫短路，可以帮我们少算一步、也能避免出错。

三目运算符
// 判断一个数是奇数还是偶数
#include <iostream>
using namespace std;

int main() {
    int n = 7;
    if (n % 2 == 0) {
        cout << "偶数" << endl;
    } else {
        cout << "奇数" << endl;
    }
    return 0;
}

// 输出：奇数
// 判断闰年：能被4整除且不能被100整除，或者能被400整除
int year = 2024;
if ((year % 4 == 0 && year % 100 != 0) || year % 400 == 0) {
    cout << "是闰年" << endl;
} else {
    cout << "不是闰年" << endl;
}

// ! 表示"取反"
bool flag = false;
if (!flag) {          // !false 就是 true
    cout << "flag 是假" << endl;
}
// 短路演示：左边已经能决定结果，右边就不算了
int x = 0;

// A 为假 → B 不计算，所以不会发生除 0 错误
if (x != 0 && 10 / x > 1) {
    cout << "成立" << endl;
} else {
    cout << "不成立" << endl;   // 走这里
}

// A 为真 → || 的右边不计算，直接整体为真
int y = 5;
if (y > 0 || 10 / y > 100) {
    cout << "成立" << endl;       // 走这里
}
// 三目运算符：条件 ? 真时取值 : 假时取值
int a = 8, b = 15;
int mx = (a > b) ? a : b;   // 取较大的那个
cout << mx << endl;           // 输出 15

// 等价于双分支：
if (a > b) { mx = a; } else { mx = b; }

// 也可以直接用在 cout 里
cout << ((a % 2 == 0) ? "偶数" : "奇数") << endl;

💡 小贴士

  • else 不写条件：else { ... } 才是对的，else (条件) 和 else; 都容易出问题
  • && 和 || 别写反：&& 要"都满足"，|| 要"满足一个就行"
  • 用 != 不用 ≠：C++ 里"不等于"是英文 !=，"等于"是两个等号 ==
  • 短路很有用：x != 0 && 10 / x > 1 里，先把 x != 0 放前面可以避免除 0
  • 三目运算符：条件 ? 真值 : 假值，冒号别漏；太复杂的判断还是用 if-else 更清楚
  • 两个分支只走一个：不要以为 if 和 else 里的代码会一起执行
