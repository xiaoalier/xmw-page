1典型题型：切绳子

题目

有 n 根绳子，要切出 k 段长度相同的小段，问每段最长能多长（结果取整）。

单调性

每段越长，能切出的段数越少——所以可以二分长度。

check

给定长度 x，累加每根能切出的段数，看总数是否 ≥ k。

📌写法
bool check(int x) {
    int cnt = 0;
    for (int i = 0; i < n; i++) cnt += a[i] / x;   // 整数除法就是能切的段数
    return cnt >= k;
}

int l = 1, r = maxLen, ans = 0;
while (l <= r) {
    int mid = (l + r) / 2;
    if (check(mid)) { ans = mid; l = mid + 1; }
    else r = mid - 1;
}

⚠ 结果要取整（向下），所以用整数二分，不要用浮点。

2浮点二分：精度怎么定

📌要求输出小数时
double l = 0, r = 1e9;
for (int step = 0; step < 100; step++) {     // 固定次数更稳
    double mid = (l + r) / 2;
    if (check(mid)) l = mid;
    else r = mid;
}
printf("%.4f", l);

⚠ 浮点二分别用 while (r - l > 1e-9)，容易死循环；固定循环 100 次最稳。

6小贴士

💡 小贴士

  • 先确认「长度 → 段数」是单调的。
  • check 里用整数除法算段数。
  • 整数答案用整数二分，不要用浮点。
  • 浮点二分固定循环次数（100 次）。
  • 上界要给够，不然会把最优解排除。
