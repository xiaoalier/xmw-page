1关系运算符与布尔变量

关系运算符

比较两个值的大小或相等，结果只有「真」或「假」。共 6 个：> >= < <= == !=。

布尔变量 bool

专门装「真 / 假」的类型，只有两个值：true（真）和 false（假）。

关系表达式有值

a > b 本身就是一个值，结果是 true 或 false，可以存进 bool 变量。

⚖六个关系运算符
运算符含义例子（a=5, b=3）结果
>大于a > btrue
>=大于等于a >= btrue
<小于a < bfalse
<=小于等于a <= bfalse
==等于（两个等号）a == bfalse
!=不等于a != btrue

⚠ 易错：判断相等要写两个等号 ==；一个等号 = 是赋值，会把右边的值塞进左边的变量。

2流程图与单分支 if

🔷单分支：条件成立才做事
// 格式：if (条件) { 条件为真时执行的语句 }
if (a > b) {
    cout << "a 比 b 大" << endl;
}

执行过程：先判断括号里的条件 → 为 真 就执行花括号里的语句；为 假 就直接跳过，什么都不做。这就是「单分支」——只有一路，没有 else。

// 关系表达式的结果可以存进 bool
#include <iostream>
using namespace std;

int main() {
    int a = 5, b = 3;
    bool bigger = (a > b);   // true
    bool equal = (a == b);  // false
    cout << bigger << " " << equal << endl;
    return 0;
}

// 输出：1 0（true 显示为 1，false 显示为 0）
// 判断一个数是不是偶数
#include <iostream>
using namespace std;

int main() {
    int n;
    cin >> n;
    if (n % 2 == 0) {
        cout << "偶数" << endl;
    }
    return 0;
}
// 判断一个数是不是正数
#include <iostream>
using namespace std;

int main() {
    int n;
    cin >> n;
    if (n > 0) {
        cout << "正数" << endl;
    }
    return 0;
}
// 判断 a 能否被 b 整除
#include <iostream>
using namespace std;

int main() {
    int a, b;
    cin >> a >> b;
    if (a % b == 0) {
        cout << "能整除" << endl;
    }
    return 0;
}
// ❌ 把判断相等写成赋值
if (a = 5) { ... }    // 这是赋值！应写 a == 5

// ❌ 条件后面多写了分号
if (a > b); {          // 分号让 if 变成了空语句
    cout << "永远会执行";
}

// ✅ 正确写法
if (a > b) {
    cout << "a 更大" << endl;
}

💡 小贴士

  • 判断相等用两个等号：== 是判断，= 是赋值，别写混。
  • if 的条件要加括号：if (条件) { ... }，括号不能少。
  • 单分支只做一件事：条件为真就执行，为假就跳过，没有 else。
  • 花括号是好习惯：即使只有一句，也写 { }，以后加语句不容易错。
  • 条件后面别加分号：if (a > b); 会让 if 变成空语句。
  • 布尔值输出：true 会显示成 1，false 显示成 0。
  • 关系表达式本身有值：可以写 bool b = (a > b);。
