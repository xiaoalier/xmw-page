第63课 · 队列

先进先出：先来的先走

1队列的特点

先进先出 FIFO

像排队买票，先来的先服务。

两端操作

队尾入队 push，队头出队 pop。

常见用途

BFS 广度优先搜索、任务排队、模拟类题目。

📌用数组模拟（循环队列思想）
int q[100005], head = 0, tail = 0;

q[tail++] = x;            // 入队（放队尾）
int y = q[head++];        // 出队（取队头）
bool empty = (head == tail);
int frontVal = q[head];

⚠ 这样写 head 会一直往后走，空间用完就没了；大数据量可以用 STL 的 queue，或者用取模做循环队列。

2BFS 里为什么用队列

📌一层一层扩散
queue<int> q;
q.push(start);
while (!q.empty()) {
    int u = q.front(); q.pop();
    for (每个相邻点 v) {
        if (没访问过) { vis[v] = 1; q.push(v); }
    }
}

队列保证「先发现的先扩展」，所以 BFS 得到的距离是最短的（边权为 1 时）。

6小贴士

💡 小贴士

  • 队列是先进先出（FIFO）。
  • 出队前判空。
  • BFS 入队时立刻标记访问。
  • 数组模拟要注意空间回收（或直接 STL）。
  • 边权为 1 的最短路用 BFS 最快。
