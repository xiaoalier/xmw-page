1第四单元知识地图

结构体与排序

结构体把信息打包；sort + cmp 按任意规则排；多关键字要一层层比。

算法思维

先看数据规模定复杂度；模拟是按规则走；枚举是穷举+判断。

递归

两件事：终止条件 + 递归关系；分叉递归注意重复计算。

📌怎么用这张地图

做题时先问自己三个问题：数据要打包吗？→ 结构体；要不要排序？→ sort + cmp；规模大不大？→ 决定能不能用 O(n²)。

2高频题型与套路

📌三类最常考的题
① 结构体 + 多关键字排序
   读入 n 条记录 → 写 cmp → sort → 按顺序输出

② 模拟
   读题，把规则拆成「每步做什么」 → for 循环按顺序执行

③ 递归
   找到「大问题 = 小问题 + 一步」 → 写终止条件 → 写递归关系

6小贴士

💡 小贴士

  • 看到「排序规则有多个条件」，就想多关键字 cmp。
  • 看到「数据规模 1e5」，就别写两层循环。
  • 看到「规则很复杂、没有公式」，先想想是不是模拟。
  • 看到「把所有情况试一遍」，就是枚举。
  • 看到「大问题 = 小问题 + 一步」，就是递归。
  • 写完代码先扫：分号、花括号、数组大小。
