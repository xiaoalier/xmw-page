在有序数组里，每次砍掉一半

1二分的前提和思路

前提：必须有序

数组没排序，二分的结果就是错的——这是最常见的错误。

每次砍一半

看中间那个：比目标小就往右找，比目标大就往左找。

为什么快

n = 100 万时，最多比较 20 次左右（log2 n）。

📌标准写法
int l = 0, r = n - 1;
while (l <= r) {
    int mid = l + (r - l) / 2;      // 防溢出写法
    if (a[mid] == x) { ans = mid; break; }
    else if (a[mid] < x) l = mid + 1;
    else r = mid - 1;
}

⚠ `mid = (l + r) / 2` 在 l、r 都很大时可能溢出；用 `l + (r - l) / 2` 更稳。

2查找的变体

📌三种常见问法
① 找某个数在不在            → 命中就返回
② 找第一个 ≥ x 的位置（lower_bound）
③ 找第一个 > x 的位置（upper_bound）

⚠ 变体题的循环条件和结果更新不一样，写之前先想清楚「答案在哪一侧」。

6小贴士

💡 小贴士

  • 二分前一定要确认数组有序。
  • mid 用 l + (r - l) / 2 更安全。
  • 找第一个 ≥ x 用 lower_bound，> x 用 upper_bound。
  • 边界更新（+1 / -1）写错最容易死循环。
  • n 很大又要多次查询时，别忘了先排序再二分。
