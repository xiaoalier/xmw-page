第34课 · 选择排序

每轮选出最小的，放到前面——交换次数最少的简单排序

1选择排序的原理

核心思想

把数组分成「已排好」和「没排好」两段。每一轮在没排好的部分里找出最小的数，和这段的第一个位置交换，已排好的部分就多一个。

找最小靠下标

用一个变量 minIdx 记住目前最小数的下标。遍历时发现更小的，就更新 minIdx，一轮结束再交换，不要一边比较一边交换。

特点

比较次数固定，约 n(n-1)/2 次；交换次数最多 n-1 次，比冒泡少。时间复杂度仍是 O(n²)，属于不稳定排序。

🀄核心代码
// 选择排序：每轮找最小，交换到前面
for (int i = 0; i < n - 1; i++) {
    int minIdx = i;                       // 先假设 i 是最小
    for (int j = i + 1; j < n; j++)
        if (a[j] < a[minIdx]) minIdx = j;  // 找到更小的就记下下标
    if (minIdx != i) swap(a[i], a[minIdx]); // 换到前面
}

⚠️ 易错：内层循环一定从 j = i + 1 开始，因为 a[i] 是这一段第一个，不用和自己比。判断条件用 <（稳定写法），写成 <= 会破坏稳定性。

3排序综合：三种排序怎么选

📊冒泡 / 插入 / 选择 对比
算法核心动作比较次数交换次数稳定性
冒泡排序相邻比较，大的后移约 n²/2较多（可优化）稳定
插入排序取数插入到前面约 n²/4（平均）移动次数较多稳定
选择排序每轮找最小再交换固定 n(n-1)/2最多 n-1 次不稳定

💡 怎么选：数据量小（几百个以内）三种都行；数据量大时优先用标准库的 sort，它更快。选择排序在「交换代价高」的场景有优势，因为交换次数少。

💡 小贴士

  • 选择排序一句话：每轮找最小，交换到这一段的最前面
  • 先记下标后交换：minIdx 记住位置，一轮结束再 swap
  • 内层从 i + 1 开始：a[i] 是这一段第一个，不用和自己比
  • 交换次数少：最多 n-1 次，这是它相对冒泡的优势
  • 不稳定：相等元素先后可能被打乱，需要稳定时慎用
  • 复杂度 O(n²)：数据量大时用 sort 更合适
  • 从高到低：把找最小改成找最大，比较符从 < 改成 >
