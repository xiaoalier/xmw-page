循环与循环嵌套：外层管行、内层管列，执行顺序与总次数

1认识循环嵌套

外层循环

也被叫作「大循环」。它每转一圈，都会带动整个内层循环完整跑一遍。习惯用 i 做变量，常常控制行。

内层循环

被外层「包住」的循环。外层每执行 1 次循环体，内层就从头到尾转完整一遍。习惯用 j，常常控制列。

执行次数

总次数 = 外层次数 × 内层次数。例：外层 3 次、内层 4 次，循环体一共执行 3 × 4 = 12 次。

🏗嵌套循环长什么样、怎么走
for (int i = 1; i <= 3; i++) {      // 外层：3 圈
    for (int j = 1; j <= 3; j++) {  // 内层：每圈 3 次
        cout << i << "," << j << endl;
    }                      // 内层跑完才回到外层
}                        // 外层进入下一圈

输出顺序：(1,1) (1,2) (1,3) → (2,1) (2,2) (2,3) → (3,1) (3,2) (3,3)。内层先跑完，外层才走一步——也就是「外层慢、内层快」。⚠️ 每换一个新外层，内层的 j 都会重新从初值开始。

// 两层循环：外层 3 圈，内层每圈 4 次
#include <iostream>
using namespace std;

int main() {
    for (int i = 1; i <= 3; i++) {      // 外层：3 圈
        for (int j = 1; j <= 4; j++) {  // 内层：每圈 4 次
            cout << "*";                // 循环体，共 3×4=12 次
        }
        cout << endl;                      // 一行画完换行
    }
    return 0;
}
// 把每一步的 i、j 都打印出来，观察顺序
#include <iostream>
using namespace std;

int main() {
    for (int i = 1; i <= 3; i++) {
        for (int j = 1; j <= 3; j++) {
            cout << "(" << i << "," << j << ") ";
        }
        cout << endl;   // 一行打完换行
    }
    return 0;
}

// 输出：
// (1,1) (1,2) (1,3)
// (2,1) (2,2) (2,3)
// (3,1) (3,2) (3,3)
// 外层走一步，内层把整行加完，再回到外层
#include <iostream>
using namespace std;

int main() {
    int sum = 0;
    for (int i = 1; i <= 3; i++) {
        for (int j = 1; j <= 4; j++) {
            sum = sum + i * j;   // 每个 (i,j) 都累加一次
        }
    }
    cout << sum << endl;          // 3 行 4 列全部 i*j 之和
    return 0;
}
// ❌ 易错 1：内层忘了写，只写一层就以为能画矩形
for (int i = 1; i <= 3; i++) cout << "*";   // 只输出 3 个，不是 3 行

// ❌ 易错 2：换行写进了内层，结果每个 * 后都换行
for (int i = 1; i <= 3; i++)
    for (int j = 1; j <= 4; j++)
        cout << "*\n";        // 换行跑到内层里了

// ✅ 正确：换行放在内层循环外面、外层循环里面
for (int i = 1; i <= 3; i++) {
    for (int j = 1; j <= 4; j++) cout << "*";
    cout << endl;
}

💡 小贴士

  • 总次数 = 外 × 内：外层转 X 圈、内层每圈 Y 次，循环体就执行 X × Y 次。
  • 外层慢、内层快：外层走一步，内层要完整跑完一遍；先看内层跑完，外层才走下一步。
  • 换新外层，内层重来：每换一个新外层，内层变量会重新从初值开始跑。
  • 循环变量习惯：外层 i、内层 j、再套一层用 k。
  • 缩进帮助看结构：内层循环比外层多缩进几格，一眼就能看清「谁套着谁」。
  • 先想总次数：写嵌套前先算一下循环体要跑几次，能帮自己检查有没有写错范围。
  • 别套太深：一般两层（画图、遍历）就够用，三层以上要多想清楚。
