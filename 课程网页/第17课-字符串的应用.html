字符串遍历、统计、查找与比较

1遍历字符串：一个字符一个字符看

用下标遍历

字符串长度记作 len，用 for (int i = 0; i < len; i++) 依次访问 s[i]。

遍历是基础

统计、查找、替换，都是"从头到尾看一遍"，看到符合条件的位置就做处理。

下标从 0 开始

第 1 个字符是 s[0]，最后一个字符是 s[len-1]。

🚶遍历框架
int len = s.length();
for (int i = 0; i < len; i++) {
    cout << s[i] << endl;   // 依次输出每个字符
}

💡 字符数组可以用 strlen(s) 求长度，for 里也可以用 s[i] != '\0' 作为结束条件。

2统计与查找

统计字符个数

看到目标字符就 cnt++。统计数字字符用 s[i] >= '0' && s[i] <= '9'。

查找字符位置

遍历时若 s[i] == ch，记下下标 i 并可以 break 提前结束。

没找到怎么办

可以先把结果设为 -1，遍历完还是 -1，就说明字符串里没有这个字符。

🔎统计和查找的写法
// 统计字符 ch 出现的次数
int cnt = 0;
for (int i = 0; i < len; i++)
    if (s[i] == ch) cnt++;

// 查找 ch 第一次出现的位置，没找到是 -1
int pos = -1;
for (int i = 0; i < len; i++) {
    if (s[i] == ch) { pos = i; break; }
}

⚠ 易错：位置是下标，从 0 开始；不要把"第几个"和"下标"弄混。

3字符串的比较

string 直接用 ==

两个 string 判断相等，可以直接写 a == b，比较方便。

字符数组用 strcmp

字符数组是数组，不能用 == 比较内容，要用 strcmp(a, b)：返回 0 表示相等。

按 ASCII 逐位比

比较时从第 1 个字符开始，按 ASCII 码逐个比，谁先小就谁小。

⚖两种比较方式
// string 比较
string a = "abc", b = "abc";
if (a == b) cout << "相等";

// 字符数组比较
char c[10] = "abc", d[10] = "abd";
int r = strcmp(c, d);   // r < 0，因为 'c' < 'd'
// r == 0 相等，r < 0 前小，r > 0 前大

💡 判断相等用 ==（两个等号），一个等号 = 是赋值，别写错。

💡 小贴士

  • 先取长度再遍历：int len = s.length();，循环写 i < len。
  • 下标从 0 开始：第 1 个字符是 s[0]，最后是 s[len-1]。
  • 查找先设 -1：遍历完还是 -1，就说明没找到。
  • 找到可以 break：只要第一个位置，找到就能提前结束循环。
  • 字符范围判断：数字 '0'~'9'，大写 'A'~'Z'，小写 'a'~'z'。
  • string 用 ==，字符数组用 strcmp：比较内容的方式不一样。
  • 空格也算字符：统计总字符数时别漏掉空格。
