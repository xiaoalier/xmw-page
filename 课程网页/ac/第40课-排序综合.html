1几种排序，怎么选

冒泡 / 选择 / 插入

都是 O(n²)。代码短、好理解，适合 n 小（几千以内）或者需要讲过程。

计数排序

数值范围不大时非常快，O(n + 范围)。用数组当下标计数。

sort

O(n log n)，比赛里默认就用它；配合 cmp 还能按任意规则排。

📌复杂度对比

n = 10 万时：O(n) 约 10 万次，O(n log n) 约 170 万次，O(n²) 约 100 亿次——所以 n 大的时候必须用 sort 或计数排序。

2计数排序的思路

📌用下标当值，数组当计数器
int cnt[1001] = {0};
for (int i = 0; i < n; i++) {
    int x; cin >> x;
    cnt[x]++;                 // 数字 x 出现一次
}
for (int v = 1; v <= 1000; v++) {
    for (int k = 0; k < cnt[v]; k++) cout << v << " ";
}

⚠ 前提是数值范围可控（比如 1~1000）。范围太大（如 1e9）就不能用。

6小贴士

💡 小贴士

  • n 大（上万）时优先 sort 或计数排序。
  • 冒泡的特点是「每轮把当前最大送到末尾」。
  • 选择排序交换次数少，冒泡相邻交换多。
  • 计数排序的前提是数值范围不大。
  • 比赛里想少写代码，直接 sort 最省事。
