1第三单元知识地图

函数：把代码装进盒子

把一段重复使用的逻辑写成函数，用参数把数据传进去，用返回值把结果带回来。程序更清晰、更好改。

位运算：和二进制打交道

把整数看成二进制，逐位做 & | ^ ~ << >> 运算，常用于状态标记、快速乘除 2 的幂。

排序：把数据排好队

冒泡、插入、选择是三种基础排序；sort 配合自定义 cmp 最常用，数据量大时更省心。

// 函数：定义 → 调用，参数传值，返回结果
int add(int a, int b) {     // 形参 a、b
    return a + b;
}

int main() {
    int x = 3, y = 5;
    int s = add(x, y);        // 实参 x、y（值传递）
    cout << s << endl;         // 8
    return 0;
}
// 位运算：逐位操作（以 6 和 3 为例）
// 6 = 110，3 = 011
cout << (6 & 3) << endl;    // 2（010）按位与
cout << (6 | 3) << endl;    // 7（111）按位或
cout << (6 ^ 3) << endl;    // 5（101）按位异或
cout << (1 << 3) << endl;    // 8  左移 = 乘 2 的幂
cout << (16 >> 2) << endl;   // 4  右移 = 除以 2 的幂

// 常用技巧：n & 1 判奇偶，n & (n-1) 去掉最低位的 1
// 三种基础排序的核心（升序）
// 1 冒泡：相邻比较，大的后移
for (int i = 0; i < n - 1; i++)
    for (int j = 0; j < n - 1 - i; j++)
        if (a[j] > a[j + 1]) swap(a[j], a[j + 1]);

// 2 插入：取出 key，前面大的后移
for (int i = 1; i < n; i++) {
    int key = a[i], j = i - 1;
    while (j >= 0 && a[j] > key) { a[j + 1] = a[j]; j--; }
    a[j + 1] = key;
}

// 3 选择：每轮找最小，交换到前面
for (int i = 0; i < n - 1; i++) {
    int minIdx = i;
    for (int j = i + 1; j < n; j++)
        if (a[j] < a[minIdx]) minIdx = j;
    if (minIdx != i) swap(a[i], a[minIdx]);
}
// sort + 自定义 cmp：结构体多关键字排序
#include <algorithm>
struct Student { string name; int score; };

bool cmp(Student a, Student b) {
    if (a.score != b.score) return a.score > b.score; // 分数降序
    return a.name < b.name;                              // 名字升序
}
sort(s, s + n, cmp);

// 记住：cmp 返回 true 表示 a 排在 b 前面
// 复杂度速查（n 为数据个数）
// 冒泡 / 插入 / 选择排序：时间 O(n²)，空间 O(1)
// sort（标准库）：一般 O(n log n)
//
// 数据量参考：
//   n ≤ 1000    → O(n²) 通常没问题
//   n 较大（如 1e5）→ 优先用 sort
//
// 稳定性：冒泡稳定、插入稳定、选择不稳定

💡 小贴士

  • 函数三件事：定义、调用、返回值，写出来要「一个函数只做一件事」
  • 值传递：形参改变不影响实参；想改实参要用引用或指针
  • 位运算记口诀：与全 1 才 1、或全 0 才 0、异或不同才 1
  • 左右移：1 << k 等于乘 2^k，x >> k 等于除以 2^k（整数）
  • 判奇偶：n & 1 为 1 是奇数，为 0 是偶数
  • 三种排序：冒泡相邻交换、插入取数插入、选择找最小交换
  • 优先用 sort：数据量大时 sort 一般比手写 O(n²) 更快
  • cmp 一句话：返回 true 表示第一个参数排在前面
