用指针把一个个结点串起来

1链表是什么

结点 = 数据 + 指针

每个结点存自己的数据和「下一个结点在哪」，像火车车厢一节接一节。

对比数组

数组要连续内存、插删除要挪位置；链表不必连续，插入删除只改几个指针。

代价

不能像数组那样 a[i] 直接跳，必须从头一个个走。

📌单链表结点
struct Node {
    int data;          // 存的数据
    Node* next;        // 指向下一个结点
};

⚠ 最后一个结点的 next 要指向 NULL，否则遍历停不下来。

2遍历与插入删除

📌常见操作
// 遍历
for (Node* p = head; p != NULL; p = p->next)
    cout << p->data << " ";

// 头插
Node* t = new Node; t->data = x;
t->next = head; head = t;

// 删除 head 后面的那个
Node* d = head->next;
head->next = d->next;
delete d;

⚠ 双链表多一个 prev 指针，删结点时可以 O(1) 找到前驱。

    Node* p = new Node;

    if (!head) head = tail = p;

6小贴士

💡 小贴士

  • 链表靠 next 串起来，最后一个指向 NULL。
  • 链表不能像数组那样用下标直接访问。
  • 插删除只改指针，不用挪数据。
  • new 出来的结点记得 delete。
  • 双链表多一个 prev，删结点更方便。
