1自增自减：++ 和 --

i++ / ++i

让变量自己加 1。单独写一行时，i++ 和 ++i 效果一样。

i-- / --i

让变量自己减 1。循环里常用来从大往小数。

放在一起才看差别

当它们出现在表达式里时，i++ 是先用后加，++i 是先加后用。

➕单独使用时：加一减一
int i = 5;
i++;      // i 变成 6，等价于 i = i + 1;
i--;      // i 又变回 5
++i;      // i 变成 6

// 放进表达式时才有区别：
int a = 5;
int b = a++;   // 先用 a(5) 赋值给 b，a 再变 6 → b=5, a=6
int c = ++a;   // a 先变 7，再赋值给 c → c=7, a=7

⚠ 易错：初学阶段复杂表达式里少混用 ++，容易看不清；i++ 单独一行最安全。

2复合赋值运算符：+= -= *= /= %=

是什么

把"先算再存回自己"缩写成一个符号，写起来更短，意思不变。

怎么用

i += 3; 就是 i = i + 3;；sum *= 2; 就是 sum = sum * 2;。

别忘了取余

n %= 10; 表示 n = n % 10;，常用来取个位。

🧮小试一下：改数字，看两种写法结果一样
int x = x +=

点「算一算」，看看 x += n 和 x = x + n 是不是一样。

3for 循环：让一段代码重复执行

四件套

for (初值; 条件; 步长) { 循环体 }，用两个分号隔成三部分。

执行顺序

先执行初值一次 → 判断条件 → 真就执行循环体 → 步长 → 再判断条件……直到条件为假。

常用格式

for (int i = 1; i <= n; i++)：从 1 数到 n，一共循环 n 次。

🔁求 1 到 n 的和：循环体每次把 i 加到 sum 上
int sum = 0;
for (int i = 1; i <= 5; i++) {
    sum += i;          // 依次加上 1,2,3,4,5
}
cout << sum << endl;   // 输出 15

// 执行过程：
// i=1 → sum=1
// i=2 → sum=3
// i=3 → sum=6
// i=4 → sum=10
// i=5 → sum=15，i 变 6 后条件 6<=5 为假，循环结束

⚠ 易错：for 的三部分之间用分号，不是逗号；漏写步长 i++ 会让循环停不下来。

// 自增自减与复合赋值
int i = 5;
i++;        // i = i + 1 → 6
i--;        // i = i - 1 → 5
i += 3;     // i = i + 3 → 8
i -= 2;     // i = i - 2 → 6
i *= 2;     // i = i * 2 → 12
i /= 4;     // i = i / 4 → 3
cout << i << endl;  // 3
// 求 1 + 2 + ... + n
#include <iostream>
using namespace std;

int main() {
    int n, sum = 0;
    cin >> n;
    for (int i = 1; i <= n; i++) {
        sum += i;
    }
    cout << sum << endl;
    return 0;
}
// 输出 1 2 3 ... n（每个数后面跟空格）
int n;
cin >> n;
for (int i = 1; i <= n; i++) {
    cout << i << " ";
}
cout << endl;

// 也可以从 0 开始数
for (int i = 0; i < n; i++) {
    cout << i << " ";   // 输出 0 1 2 ... n-1
}
// 倒着数：n, n-1, ..., 1
int n;
cin >> n;
for (int i = n; i >= 1; i--) {
    cout << i << " ";
}
cout << endl;

// 每次加 2：输出 2 4 6 8 ...
for (int i = 2; i <= 10; i += 2) {
    cout << i << " ";
}

💡 小贴士

  • for 三部分用分号隔开：for (初值; 条件; 步长)，不是逗号
  • 循环次数怎么数：for (i=1; i<=n; i++) 循环 n 次；i<n 则循环 n 次但 i 从 0 到 n-1
  • 别忘了步长：漏写 i++ 可能造成死循环
  • sum 记得先归零：累加前写 int sum = 0;，不然结果会算错
  • 复合赋值更简洁：sum += i 和 sum = sum + i 一样
  • 单独用 ++ 不必纠结：i++ 和 ++i 写在单独一行时结果相同
