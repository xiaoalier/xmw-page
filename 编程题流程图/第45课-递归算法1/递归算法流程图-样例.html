【递归】倒序输出

课堂练习 · 基础必会

给出一个正整数 n，把 n 倒序输出（例：123 → 3 2 1）。要求用递归完成。

要点
  • 先输出、后递归 → 天然倒序
  • 边界 n==0 时 return，防止无限递归
2

【递归】进制转换

课堂练习 · 基础必会

输入十进制整数 n，转成二进制输出（例：6 → 110）。用递归完成。

要点
  • 先递归、回溯时输出 → 天然正序（高位在前）
  • 对比上一题：输出时机不同，顺序就不同
3

【魔法数字的能量和】

成长题

定义“能量和”= 各位数字之和（456 → 4+5+6=15）。写递归函数求非负整数的能量和，边界 n==0。

要点
  • 本题是“有返回值”的递归：把结果一层层带回来
  • 答案 = 当前位 + 剩余位的能量和
4

【星际频段转换】

挑战题

把十进制非负整数 N 转成 K 进制并倒序输出，K ≤ 9，边界 n==0，主函数对 0 特判。

要点
  • K=2 是二进制、K=8 是八进制……同一套递归通吃
  • 注意 0 的特判在 main 里做
