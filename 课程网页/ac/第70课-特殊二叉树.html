满二叉树、完全二叉树、二叉搜索树

1三种特殊形态

满二叉树

每一层都是满的，深度 h 有 2^h - 1 个结点。

完全二叉树

除最后一层外都满，最后一层从左往右连续排列。堆就是完全二叉树。

二叉搜索树 BST

左子树都比根小，右子树都比根大；中序遍历是升序。

📌BST 的查找
// 查找 x 是否存在
Node* p = root;
while (p) {
    if (p->val == x) return true;
    else if (x < p->val) p = p->l;
    else p = p->r;
}
return false;

⚠ BST 查找平均 O(log n)，但如果插入的数据是有序的，会退化成一条链，变成 O(n)。

2怎么判断完全二叉树

📌层序遍历，遇到空之后不能再出现结点
bool ok = true, seenEmpty = false;
queue<Node*> q; q.push(root);
while (!q.empty()) {
    Node* p = q.front(); q.pop();
    if (!p) { seenEmpty = true; continue; }
    if (seenEmpty) ok = false;      // 空之后又有结点 → 不是完全二叉树
    q.push(p->l); q.push(p->r);
}

6小贴士

💡 小贴士

  • 满二叉树每层都满；完全二叉树最后一层靠左。
  • 堆是完全二叉树的典型应用。
  • BST 中序升序，查找平均 O(log n)。
  • BST 有序插入会退化成链。
  • 判完全二叉树要按层序看空位。
