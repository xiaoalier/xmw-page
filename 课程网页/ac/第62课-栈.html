第62课 · 栈

后进先出：最后放进去的最先拿出来

1栈的特点

后进先出 LIFO

像叠盘子，只能从最上面拿，最后放的最先取。

只在顶部操作

入栈 push 和出栈 pop 都发生在栈顶。

常见用途

括号匹配、表达式求值、撤销操作、DFS 的非递归写法。

📌用数组模拟栈
int st[100005], top = 0;      // top 指向栈顶的下一个位置

st[top++] = x;                 // 入栈
int y = st[--top];             // 出栈
bool empty = (top == 0);
int topVal = st[top - 1];

⚠ 出栈前一定要判空（top == 0 时再 pop 就越界了）。

2例题：括号匹配

📌遇到左括号入栈，遇到右括号出栈比对
bool ok(string s) {
    stack<char> st;
    for (char ch : s) {
        if (ch == '(' || ch == '[') st.push(ch);
        else {
            if (st.empty()) return false;
            char t = st.top(); st.pop();
            if (ch == ')' && t != '(') return false;
            if (ch == ']' && t != '[') return false;
        }
    }
    return st.empty();          // 最后必须清空
}

6小贴士

💡 小贴士

  • 栈是后进先出（LIFO）。
  • 出栈前一定判空。
  • 括号匹配最后要检查栈清空。
  • STL 的 stack 只有 push/pop/top/empty。
  • 递归的过程本质就是栈。
