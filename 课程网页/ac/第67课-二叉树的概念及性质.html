1二叉树的结构

每个结点最多两个孩子

左孩子和右孩子，左右不能随意交换。

常见类型

满二叉树（每层都满）、完全二叉树（除最后一层外都满，最后一层靠左）。

编号规律

完全二叉树按层编号后，结点 i 的左孩子是 2i、右孩子是 2i+1、父亲是 i/2。

📌几条常用性质
第 i 层最多 2^(i-1) 个结点
深度为 h 的二叉树最多 2^h - 1 个结点
叶子数 = 度为 2 的结点数 + 1
n 个结点的完全二叉树高度 = floor(log2 n) + 1

⚠ 这些是选择题的高频考点，建议直接背下来。

2完全二叉树为什么用数组存

📌按层编号，父子关系能直接算
int a[100005];              // a[1] 是根

// 结点 i 的左右孩子
int lc = i * 2, rc = i * 2 + 1;
// 结点 i 的父亲
int fa = i / 2;

⚠ 数组要开到 4n 或更大，防止越界（最坏情况是链状）。
