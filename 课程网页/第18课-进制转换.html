1什么是进制

逢 N 进一

进制就是"进位计数制"。十进制逢十进一，二进制逢二进一，八进制逢八进一，十六进制逢十六进一。

基数和数码

基数就是每一位能用几个数字。二进制基数 2（0、1），十进制基数 10（0~9），十六进制基数 16（0~9 和 A~F）。

每一位都有"权"

权 = 基数 ^ 位数。位数从右往左、从 0 开始数。十进制的个位权是 10⁰，十位是 10¹。

2任意进制 → 十进制：按权展开求和

方法是"按权展开"

把每一位数字，乘以它所在位置的权（基数的 n 次方），再把所有结果加起来。

位数从右往左数

最右边一位的位数是 0，往左依次是 1、2、3……权就是 基数 ^ 位数。

举个例子

二进制 1011 = 1×2³ + 0×2² + 1×2¹ + 1×2⁰ = 8 + 0 + 2 + 1 = 11。

⬅按权展开的过程
// 十六进制 2AF 转十进制
2AF = 2×16² + A×16¹ + F×16⁰
    = 2×256 + 10×16 + 15×1
    = 512 + 160 + 15
    = 687

⚠ 易错：字母 A~F 要先换成数字 10~15 再乘，别直接当字母算。

3十进制 → 任意进制：除基取余，倒序排列

除基取余法

用目标基数反复去除十进制数，每次记下余数，直到商为 0 为止。

余数要"倒着读"

把得到的余数从下往上（从最后一个到第一个）排起来，就是结果。

余数大于 9 用字母

转十六进制时，如果余数是 10~15，要写成 A~F，不能直接写数字。

➡除基取余的过程（十进制 45 转二进制）
45 ÷ 2 = 22 余 1   ↑
22 ÷ 2 = 11 余 0   ↑
11 ÷ 2 =  5 余 1   ↑  从下往上读余数
 5 ÷ 2 =  2 余 1   ↑
 2 ÷ 2 =  1 余 0   ↑
 1 ÷ 2 =  0 余 1   ↑

结果：45 = 101101(二进制)

💡 判断有没有写对：位数对了、倒序读了，可以用"按权展开"再算回去检验。

// 除基取余：十进制转二进制，余数倒序输出
#include <iostream>
using namespace std;

int main() {
    int n;
    cin >> n;
    int ans[40], cnt = 0;
    if (n == 0) { cout << 0; return 0; }
    while (n > 0) {
        ans[cnt] = n % 2;   // 取余
        cnt++;
        n = n / 2;           // 除以基数
    }
    for (int i = cnt - 1; i >= 0; i--)  // 倒序输出
        cout << ans[i];
    return 0;
}
// 按权展开：二进制转十进制
int ans = 0;
int w = 1;                 // 当前位的权，从 2^0 开始
while (n > 0) {
    ans += (n % 10) * w;   // 取当前最低位，乘以权
    w = w * 2;               // 权乘以基数
    n = n / 10;
}
cout << ans << endl;

💡 小贴士

  • 权怎么算：权 = 基数 ^ 位数，位数从右往左、从 0 开始数。
  • N 进制 → 十进制：按权展开求和，每位乘权再相加。
  • 十进制 → N 进制：除基取余，直到商为 0，余数倒序读。
  • 十六进制字母：A~F 分别表示 10~15，转的时候要先换数字。
  • 两种方法互相检验：转完用另一种方法算回去，看对不对。
  • 特殊值别忘：十进制 0 转任何进制都是 0。
  • 八进制↔二进制：1 位八进制 = 3 位二进制；1 位十六进制 = 4 位二进制。
