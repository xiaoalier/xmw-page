矩阵求和、转置、最值、对角线，一套两层循环走天下

1四种常见应用

① 求和

用两层循环把每个 a[i][j] 加进同一个变量。想求每行的和，就把求和变量放在外层，每行先清零。

② 转置

把「第 i 行第 j 列」搬到「第 j 行第 i 列」，也就是 b[j][i] = a[i][j]。行和列互换，矩阵会「翻个身」。

③ 最值

先假设第一个数是最大（最小）的，再遍历剩下的，遇到更大（更小）的就更新，顺便记住位置 (i,j)。

④ 对角线

正方形矩阵里，主对角线是 i == j 的格子（左上到右下），副对角线是 i + j == n - 1。

🧩核心就一句话：外层行、内层列，对每个 a[i][j] 做处理
// 求和：把所有元素加起来
int sum = 0;
for (int i = 0; i < n; i++)
    for (int j = 0; j < m; j++)
        sum = sum + a[i][j];

// 转置：行列互换
for (int i = 0; i < n; i++)
    for (int j = 0; j < m; j++)
        b[j][i] = a[i][j];

// 主对角线：只处理 i == j 的格子
for (int i = 0; i < n; i++)
    sum = sum + a[i][i];

⚠️ 转置的结果矩阵是「原列数 × 原行数」，定义 b 的时候别把行列写反；对角线只有正方形矩阵（n 行 n 列）才方便这样取。

// 求矩阵所有元素之和
#include <iostream>
using namespace std;

int a[100][100];

int main() {
    int n, m;
    cin >> n >> m;
    for (int i = 0; i < n; i++)
        for (int j = 0; j < m; j++)
            cin >> a[i][j];

    int sum = 0;
    for (int i = 0; i < n; i++) {
        for (int j = 0; j < m; j++) {
            sum = sum + a[i][j];
        }
    }
    cout << sum << endl;
    return 0;
}
// 矩阵转置：b[j][i] = a[i][j]
#include <iostream>
using namespace std;

int a[100][100], b[100][100];

int main() {
    int n, m;
    cin >> n >> m;
    for (int i = 0; i < n; i++)
        for (int j = 0; j < m; j++)
            cin >> a[i][j];

    for (int i = 0; i < n; i++)
        for (int j = 0; j < m; j++)
            b[j][i] = a[i][j];   // 行列互换

    for (int i = 0; i < m; i++) {   // 结果有 m 行
        for (int j = 0; j < n; j++) {   // 每行 n 个
            cout << b[i][j] << " ";
        }
        cout << endl;
    }
    return 0;
}
// 求最大值和它的位置
#include <iostream>
using namespace std;

int a[100][100];

int main() {
    int n, m;
    cin >> n >> m;
    for (int i = 0; i < n; i++)
        for (int j = 0; j < m; j++)
            cin >> a[i][j];

    int mx = a[0][0], mi = 0, mj = 0;  // 先假设左上角最大
    for (int i = 0; i < n; i++) {
        for (int j = 0; j < m; j++) {
            if (a[i][j] > mx) {   // 遇到更大的就更新
                mx = a[i][j];
                mi = i;
                mj = j;
            }
        }
    }
    cout << mx << " " << mi << " " << mj << endl;
    return 0;
}
// 主对角线之和（正方形矩阵）
#include <iostream>
using namespace std;

int a[100][100];

int main() {
    int n;
    cin >> n;
    for (int i = 0; i < n; i++)
        for (int j = 0; j < n; j++)
            cin >> a[i][j];

    int sum = 0;
    for (int i = 0; i < n; i++) {
        sum = sum + a[i][i];   // 行下标 == 列下标
    }
    cout << sum << endl;
    return 0;
}

💡 小贴士

  • 求和要清变量：求总和时 sum = 0 放循环外面；求每行的和时，清零放外层循环里。
  • 转置靠行列互换：核心就是 b[j][i] = a[i][j]，结果矩阵是「原列数 × 原行数」。
  • 最值先设首元素：先把 a[0][0] 当作最大（最小），再逐个比较更新。
  • 主对角线：只处理 i == j 的格子，一个循环就够了。
  • 副对角线：条件是 i + j == n - 1，别和主对角线混了。
  • 对角线要方阵：n 行 n 列才方便这样取，行列不等时先想清楚题意。
  • 越界要避免：定义多大就用到下标多大减 1，转置写 b 时尤其容易写反行列。
