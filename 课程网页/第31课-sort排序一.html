1认识 sort 函数

它在哪里

sort 写在 <algorithm> 头文件里，用之前要 #include <algorithm>。

升序写法

sort(a, a + n); 会把 a[0] 到 a[n-1] 排成从小到大。

降序写法

sort(a, a + n, greater<int>()); 排成从大到小。

📐两个参数是"左闭右开"的区间
int a[5] = {3, 1, 4, 1, 5};

sort(a, a + 5);                    // 1 1 3 4 5  升序
sort(a, a + 5, greater<int>());  // 5 4 3 1 1  降序

// 区间 [a, a+5) 表示：从 a[0] 开始，到 a[4] 结束
// a+5 指向"最后一个元素的下一个位置"

⚠ 易错：第二个参数是 a + n（不是 a + n - 1）；写 greater<int> 时那对括号不能省。

2数组和 vector 都能排

数组

sort(a, a + n); 用数组首地址和结束地址作为区间。

vector

sort(v.begin(), v.end()); 用迭代器表示区间。

部分排序

sort(a + l, a + r + 1); 可以只排下标 l 到 r 这一段。

🧩例子：只把数组中间一段排序
int a[5] = {5, 3, 4, 1, 2};
sort(a + 1, a + 4);   // 只排下标 1~3：5 1 3 4 2

// 想排下标 l 到 r（含 r），写法是 sort(a + l, a + r + 1)

💡 sort 内部用的是快速排序等高效算法，比自己写冒泡、选择排序快很多，写题时优先用它。

易错对比
#include <iostream>
#include <algorithm>     // sort 在这里
using namespace std;

int a[105];

int main() {
    int n;
    cin >> n;
    for (int i = 0; i < n; i++) cin >> a[i];

    sort(a, a + n);              // 升序：从小到大

    for (int i = 0; i < n; i++) cout << a[i] << " ";
    return 0;
}
// 降序：从大到小
sort(a, a + n, greater<int>());
// 注意 greater<int> 后面那对括号不能少

// 也可以排完升序后，反过来输出：
sort(a, a + n);
for (int i = n - 1; i >= 0; i--)
    cout << a[i] << " ";
#include <vector>
#include <algorithm>

vector<int> v;
// ... 往 v 里放数据 ...
sort(v.begin(), v.end());              // 升序
sort(v.begin(), v.end(), greater<int>()); // 降序

// 输出
for (int i = 0; i < v.size(); i++) cout << v[i] << " ";
// ❌ 忘记 #include <algorithm> 就用 sort
// ❌ 第二个参数写成 a + n - 1（应该是 a + n）
// ❌ greater<int> 漏了括号，写成 greater<int>
// ❌ 想排下标 l~r，却写成 sort(a + l, a + r)（会漏掉 a[r]）
// ✅ 记住区间是左闭右开，右边界要"多一个"

💡 小贴士

  • 先加头文件：#include <algorithm>，不然 sort 用不了。
  • 升序：sort(a, a + n); 默认从小到大。
  • 降序：sort(a, a + n, greater<int>());，括号别丢。
  • 区间是左闭右开：排 a[0]~a[n-1] 写 a + n，不是 a + n - 1。
  • vector 写法：sort(v.begin(), v.end())。
  • 只排一段：下标 l 到 r 写 sort(a + l, a + r + 1)。
  • 写题优先用它：比手写冒泡、选择排序又快又省事。
