第57课 · 埃氏筛法

一次性筛出 n 以内的所有质数

1为什么不能一个个判断

逐个判断太慢

每个数试除到平方根，n = 1e6 时总运算量很大。

筛法的想法

把 2 的倍数、3 的倍数、5 的倍数…全部划掉，剩下的就是质数。

复杂度

O(n log log n)，n = 1e6 也很快。

📌写法
bool isPrime[1000005];
for (int i = 2; i <= n; i++) isPrime[i] = true;

for (int i = 2; i * i <= n; i++)
    if (isPrime[i])
        for (int j = i * i; j <= n; j += i)
            isPrime[j] = false;      // 划掉 i 的倍数

⚠ 内层从 i*i 开始（比 i*i 小的倍数已经被更小的质数划掉了）；⚠ 判断条件用 i*i <= n。

2筛法的常见变形

📌还能顺便统计
// 统计质数个数
int cnt = 0;
for (int i = 2; i <= n; i++) if (isPrime[i]) cnt++;

// 线性筛（欧拉筛）：每个合数只被最小质因子划一次，O(n)

6小贴士

💡 小贴士

  • 筛法前把数组全部设为 true，再把 0、1 设为 false。
  • 内层从 i*i 开始，能省不少时间。
  • 外层条件用 i*i <= n。
  • 数组开 n+1，注意下标别越界。
  • 只要求 n 以内质数时，筛法比逐个判断快得多。
