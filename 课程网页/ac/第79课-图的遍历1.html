1图的 DFS 遍历

和网格 DFS 一样

区别只是「邻居」由 g[u] 给出，不用自己算四个方向。

标记访问

每个点只走一次，靠 vis 数组。

遍历序列

记录下访问顺序，就是「DFS 序」。

📌代码
void dfs(int u) {
    vis[u] = 1;
    cout << u << " ";            // 访问顺序
    for (int v : g[u])
        if (!vis[v]) dfs(v);
}

⚠ 图可能不连通，要「对所有点都试一次」才能走遍全图。

2DFS 序有什么用

📌常见用途
① 判断两点是否连通
② 求欧拉路径 / 拓扑排序的辅助
③ 树上的 DFS 序可以把子树变成一段连续区间

⚠ 遍历顺序和邻接表里邻居的存储顺序有关，不同存法结果可能不同。

6小贴士

💡 小贴士

  • DFS 靠 vis 标记防重复。
  • 图不连通时，外层要对所有点试一次。
  • 无向图边要双向加。
  • DFS 序和存边顺序有关。
  • 求最短路用 BFS，不用 DFS。
