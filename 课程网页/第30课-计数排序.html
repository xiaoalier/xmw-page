1计数排序是什么

不开比较，开"桶"

它不是两两比较大小，而是统计每个数字出现了几次，把次数装在"桶"里。

适用条件

适合排序范围不太大的整数。数字太分散、范围太大时，桶会开得太多，浪费空间。

速度很快

时间大约 O(n + k)（k 是数字范围），比冒泡排序快很多。

💡 记住核心：计数排序 = 统计每个数出现了几次 + 按数字从小到大把桶里的数倒出来。

2计数排序的四个步骤

🪣以数组 3 1 4 1 2 为例
// 1. 找出最大值 max = 4，确定桶的范围 0 ~ 4
// 2. 开桶 cnt[0..max]，初始都是 0
cnt = [ 0, 0, 0, 0, 0 ]
       0  1  2  3  4   ← 桶的下标就是数字本身

// 3. 遍历原数组，遇到 x 就 cnt[x]++
遇到 3 -> cnt[3]++
遇到 1 -> cnt[1]++
遇到 4 -> cnt[4]++
遇到 1 -> cnt[1]++
遇到 2 -> cnt[2]++

结果：cnt = [ 0, 2, 1, 1, 1 ]
              0  1  2  3  4

// 4. 从下标 0 到 max 依次输出，桶里有几个就输出几个
0 有 0 个
1 有 2 个  -> 输出 1 1
2 有 1 个  -> 输出 2
3 有 1 个  -> 输出 3
4 有 1 个  -> 输出 4
排序结果：1 1 2 3 4

⚠ 易错：桶数组大小要 ≥ max + 1（要能放下 0）；数字 0 也要统计，别忽略；数据范围太大时不适合用计数排序。

// 计数排序：先统计，再按桶顺序输出
#include <iostream>
using namespace std;

int a[1005];
int cnt[1005];   // 桶数组

int main() {
    int n, mx = 0;
    cin >> n;
    for (int i = 0; i < n; i++) {
        cin >> a[i];
        if (a[i] > mx) mx = a[i];   // 找最大值
    }
    for (int i = 0; i < n; i++)
        cnt[a[i]]++;                // 计数
    for (int v = 0; v <= mx; v++)
        for (int c = 0; c < cnt[v]; c++)
            cout << v << " ";      // 按桶顺序输出
    return 0;
}
// 只统计每个数字出现的次数
int cnt[101] = {0};   // 统计 1~100 出现的次数
int n;
cin >> n;
for (int i = 0; i < n; i++) {
    int x;
    cin >> x;
    cnt[x]++;               // x 出现一次就加一
}
// 输出每个出现过的数字和它的次数
for (int v = 1; v <= 100; v++)
    if (cnt[v] > 0)
        cout << v << " 出现 " << cnt[v] << " 次" << endl;
// 应用一：找出现次数最多的数（众数）
int best = 0, bestCnt = 0;
for (int v = 0; v <= mx; v++)
    if (cnt[v] > bestCnt) { bestCnt = cnt[v]; best = v; }

// 应用二：去掉重复数字，从小到大输出去重结果
for (int v = 0; v <= mx; v++)
    if (cnt[v] > 0) cout << v << " ";

// 应用三：统计有多少种不同的数字
int kinds = 0;
for (int v = 0; v <= mx; v++)
    if (cnt[v] > 0) kinds++;
// ❌ 桶数组开得太小，放不下最大值（要 max + 1）
// ❌ 忘了统计数字 0，从 1 开始遍历就漏了
// ❌ 拿计数排序去排小数或字符串（它一般只排整数）
// ❌ 数据范围是 1e9 还硬开桶，内存直接爆掉
// ✅ 先想清楚：这些数据是不是"范围不大的整数"

💡 小贴士

  • 核心两句话：统计每个数出现几次，再按数字从小到大输出。
  • 桶下标 = 数字本身：cnt[x] 存的就是数字 x 出现的次数。
  • 桶要开够：大小 ≥ 最大值 + 1，别忘了数字 0。
  • 先想范围：范围不大的整数才适合；范围太大就别用计数排序。
  • 输出要遍历桶：从 0 到 max，桶里有几个就输出几个，自然就是升序。
  • 常见应用：统计频次、去重、找众数、求不同数字个数。
  • 可以升序也可以降序：把遍历桶的方向倒过来，就是从大到小。
