1参数是怎么传进函数的

值传递

C++ 默认按值传递：调用时把实参的值复制一份给形参。函数里改的是复制品，不影响原来的实参。

形参是复制品

形参就像函数自己临时的一个盒子。函数结束后盒子被销毁，里面的改动也就没了。

作用域

变量能起作用的范围叫作用域。函数里定义的局部变量只在本函数内有效；全局变量到处能用。

📦一句话记住

💡 值传递：实参 → 复制 → 形参。函数里对形参动手，改的是副本，原变量不动。想真正改变实参，要用引用传递（int &a，本课先了解）。

// 值传递：形参改变，实参不受影响
#include <iostream>
using namespace std;

void change(int a, int b) {
    a = 100;   // 改的是形参（副本）
    b = 200;
}

int main() {
    int x = 3, y = 5;
    change(x, y);
    cout << x << " " << y << endl;   // 仍然是 3 5
    return 0;
}
// 局部变量：只在本函数内有效
#include <iostream>
using namespace std;

void fun() {
    int t = 7;   // 局部变量，fun 结束后就没了
    cout << t << endl;
}

int main() {
    fun();
    // cout << t;  // ❌ 这里访问不到 fun 里的 t
    return 0;
}
// 全局变量：写在所有函数外面，哪里都能用
#include <iostream>
using namespace std;

int g = 10;   // 全局变量

void show() {
    cout << g << endl;   // 函数里也能读到 g
}

int main() {
    show();
    cout << g << endl;
    return 0;
}
// 同名变量：局部优先（就近原则）
#include <iostream>
using namespace std;

int g = 10;   // 全局

void fun() {
    int g = 99;   // 局部，暂时"盖住"全局的 g
    cout << g << endl;   // 输出 99
}

int main() {
    fun();
    cout << g << endl;   // 输出 10（全局没被改）
    return 0;
}
// 引用传递（了解）：加一个 &，函数里改 a 就会改到实参
#include <iostream>
using namespace std;

void change2(int &a) {
    a = 100;   // a 是实参的"别名"，改它实参也变
}

int main() {
    int x = 3;
    change2(x);
    cout << x << endl;   // 输出 100
    return 0;
}

💡 小贴士

  • 值传递是"复制"：实参的值复制给形参，函数里改形参不影响实参
  • 形参是局部变量：只在函数内有效，函数一结束就销毁
  • 全局变量写在函数外：所有函数都能访问，但代码多了容易乱，少用为宜
  • 同名就近原则：函数里出现和全局同名的局部变量时，函数内用的是局部那个
  • 想改实参用引用：形参加 &（如 int &a）就变成引用传递，这一点先有个印象
  • 函数间传值靠参数和返回值：需要多个结果时，可以用返回值或引用传递
