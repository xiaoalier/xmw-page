二维递推：数字三角形、路径计数

1二维递推：状态有两个下标

什么时候用

答案跟「第几行、第几列」都有关系时，就用 f[i][j]。

从上一层推下来

通常是 f[i][j] 由上一行的相邻两个（或左边一格）推出来。

顺序很重要

填表要保证「用到的格子已经算过」，一般按行从上往下。

📌数字三角形：从顶走到底，和最大
// f[i][j]：从顶走到 (i,j) 的最大和
f[1][1] = a[1][1];
for (int i = 2; i <= n; i++)
    for (int j = 1; j <= i; j++)
        f[i][j] = max(f[i-1][j-1], f[i-1][j]) + a[i][j];
// 答案 = max(f[n][1..n])

⚠ 边界 j=1 和 j=i 只有一条来路，`f[i-1][0]`、`f[i-1][i]` 要当作 0 或负无穷处理。

2路径计数：过河卒

📌只能往右、往下走，问有多少条路
f[0][0] = 1;                       // 起点 1 条路
for (int i = 0; i <= n; i++)
    for (int j = 0; j <= m; j++) {
        if (i == 0 && j == 0) continue;
        if (i > 0) f[i][j] += f[i-1][j];   // 从上边来
        if (j > 0) f[i][j] += f[i][j-1];   // 从左边来
    }

⚠ 有障碍（马的控制点）时，把那一格标记成 0 条路即可。

6小贴士

💡 小贴士

  • 先想清楚 f[i][j] 代表什么。
  • 边界格单独处理，别让下标越界。
  • 自顶向下用 f[i-1]，自底向上用 f[i+1]，别混。
  • 路径计数类题要用 long long。
  • 只依赖上一行时，可以用一维滚动数组省内存。
