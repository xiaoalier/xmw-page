结构体 + 自定义比较函数 cmp，想怎么排就怎么排

1为什么需要自定义比较函数

sort 默认怎么比

sort 默认用 < 来比较，所以整数、字符会从小到大排。它不知道你的结构体该按什么排。

结构体没有默认序

两个 Student 谁大谁小？是按分数，还是按名字？编译器不知道，所以要我们写一个 cmp 函数告诉它。

cmp 的一句话规则

cmp(a, b) 返回 true 就表示：a 应该排在 b 前面。记住这句话，方向就不会弄反。

🧭cmp 的写法与含义
bool cmp(Student a, Student b) {
    return a.score > b.score;   // 分数大的排前面 → 降序
}
sort(s, s + n, cmp);            // 把 cmp 的名字当参数传进去

⚠️ 易错：别把 > 和 < 记反。写 a.score > b.score 是降序（大在前）；写 a.score < b.score 是升序（小在前）。

3C++ 里怎么写

整数升序降序
自定义 cmp（整数）
结构体按分数降序
多关键字排序
易错对比
// 没有 cmp 时，sort 默认从小到大（升序）
#include <iostream>
#include <algorithm>
using namespace std;

int main() {
    int a[5] = {3, 1, 4, 1, 5};
    sort(a, a + 5);              // 1 1 3 4 5
    return 0;
}
// 自己写规则：从大到小
#include <iostream>
#include <algorithm>
using namespace std;

bool cmp(int a, int b) {
    return a > b;                // a 比 b 大 → a 排前面
}

int main() {
    int a[5] = {3, 1, 4, 1, 5};
    sort(a, a + 5, cmp);        // 5 4 3 1 1
    return 0;
}
// 结构体数组：按分数从高到低
#include <iostream>
#include <algorithm>
#include <string>
using namespace std;

struct Student {
    string name;
    int score;
};

bool cmp(Student a, Student b) {
    return a.score > b.score;    // 分数高的排前面
}

int main() {
    int n; cin >> n;
    Student s[105];
    for (int i = 0; i < n; i++)
        cin >> s[i].name >> s[i].score;
    sort(s, s + n, cmp);
    for (int i = 0; i < n; i++)
        cout << s[i].name << " " << s[i].score << endl;
    return 0;
}
// 多关键字：先按分数降序，分数相同按名字升序
bool cmp(Student a, Student b) {
    if (a.score != b.score)
        return a.score > b.score;   // 分数高的在前
    return a.name < b.name;         // 分数一样，名字小的在前
}

// 也可以写成一行：
// return a.score != b.score ? a.score > b.score : a.name < b.name;
// ❌ 错误 1：cmp 用了 <= 或 >=，违反严格弱序，可能运行错误
bool cmp(Student a, Student b) { return a.score >= b.score; } // ❌

// ✅ 只用 > 或 <
bool cmp(Student a, Student b) { return a.score > b.score; }  // ✅

// ❌ 错误 2：忘了 #include <algorithm>
// ❌ 错误 3：sort 的第三个参数写了 cmp 却忘了写括号？其实传函数名，不写括号
sort(s, s + n, cmp);    // ✅ 传名字
// sort(s, s + n, cmp());  // ❌ cmp 不是无参函数

// ⚠️ 提醒：cmp 里比较的两个参数类型，要和数组元素类型一致

💡 小贴士

  • cmp 一句话记住：返回 true 表示「第一个参数排在前面」
  • 方向别记反：a > b 降序、a < b 升序
  • 要写 #include <algorithm>：sort 在这个头文件里
  • 传函数名不写括号：sort(s, s + n, cmp);
  • 严格弱序：cmp 里只用 < 或 >，不要用 <=、>=
  • 想稳定排序：可以用 stable_sort，相等元素的先后顺序保持不变
  • 多关键字：先比第一关键字，相等时再比第二关键字
