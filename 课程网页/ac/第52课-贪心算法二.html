区间问题：按结束时间排序，能选最多

1区间调度：最多能参加几个活动

问题

给 n 个活动，每个有开始和结束时间，同一时间只能参加一个，问最多能参加几个。

贪心规则

按「结束时间早」排序，能接上就选。

为什么这样对

越早结束，后面剩下的时间越多，能塞进更多活动。

📌写法
sort(a, a + n, cmp);           // 按结束时间升序

int last = 0, cnt = 0;
for (int i = 0; i < n; i++) {
    if (a[i].s >= last) {        // 能接上
        cnt++;
        last = a[i].e;           // 更新当前结束时间
    }
}

⚠ 排序的对象是结构体，cmp 要按结束时间比；判断能不能接上，是看开始时间 ≥ 上一个的结束时间。

2几类常见区间贪心

📌按题目要求选排序关键字
① 最多不相交区间   → 按「结束时间」升序
② 最少用几个点覆盖 → 按「结束时间」升序
③ 区间合并         → 按「开始时间」升序
④ 最少箭数射气球   → 按「结束位置」升序

⚠ 四类题长得很像，但排序关键字不同——先判断「题目要什么」，再决定按谁排。

6小贴士

💡 小贴士

  • 先判断题目要的是什么（最多几个？合并？覆盖？）。
  • 最多不相交区间 → 按结束时间排。
  • 区间合并 → 按开始时间排。
  • 记得更新 last（当前结束时间）。
