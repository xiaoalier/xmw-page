判环与拓扑排序：有向图里谁先谁后

1有向图里判断有没有环

无向图判环

边数 ≥ 点数 且有重边/回路；DFS 遇到已访问且不是父亲的点，说明有环。

有向图判环

用三种状态：未访问 0、在栈上 1、已完成 2；DFS 中遇到状态 1 的点，说明有环。

拓扑排序

把点排成「所有边都从前指向后」的顺序；有环就排不出来。

📌拓扑排序（Kahn 算法）
// 统计每个点的入度
for (每条边 u→v) indeg[v]++;

queue<int> q;
for (int i = 1; i <= n; i++) if (indeg[i] == 0) q.push(i);

while (!q.empty()) {
    int u = q.front(); q.pop();
    ans.push_back(u);              // 输出顺序
    for (int v : g[u])
        if (--indeg[v] == 0) q.push(v);
}

if (ans.size() != n) 有环;

⚠ 最后答案数量不等于 n，就说明有环——这是判环的常用技巧。

2常见应用

📌谁先谁后
① 课程先修关系（A 学完才能学 B）
② 任务依赖顺序
③ 判断有向图是否 DAG（有向无环图）

⚠ 拓扑序可能不唯一，题目一般只要求输出任意一种（或按编号最小）。

6小贴士

💡 小贴士

  • 拓扑排序只适用于有向无环图。
  • 先统计入度，入度 0 的先入队。
  • 输出点数不足 n 就是有环。
  • 有向图判环用「在栈上」状态。
  • 无向图判环要跳过父亲结点。
