1认识 break 和 continue

break：跳出整个循环

一遇到 break，整个循环立刻结束，后面的循环都不再执行。适合「找到了就停」。

for (int i = 1; i <= 5; i++) {
    if (i == 3) break;   // 到 3 就停
    cout << i;           // 输出 1 2
}
continue：跳过本次

一遇到 continue，跳过本次循环剩下的代码，直接进入下一次循环。适合「这些不要」。

for (int i = 1; i <= 5; i++) {
    if (i % 2 == 1) continue;  // 奇数跳过
    cout << i;                  // 输出 2 4
}
for / while 都能用

两者都能放进 for、while、do-while。while 里用 continue 要小心（见第 2 节）。

对比breakcontinue
作用跳出整个循环跳过本次循环体剩余部分
循环还继续吗不继续，直接到循环后面继续，进入下一次循环
for 里下一步去哪循环外的下一条语句循环的「更新」部分
while 里下一步去哪循环外的下一条语句循环的「条件判断」
典型用途找到答案就停、退出死循环过滤掉不该处理的数

2两个易错点

while 里 continue 要小心

while 里一遇到 continue 就跳回条件判断。如果变量还没更新就 continue，条件永远不变，就会死循环。

// ❌ i++ 在 continue 后面，永远到不了
int i = 1;
while (i <= 5) {
    if (i % 2 == 0) continue;
    cout << i;
    i++;
}

// ✅ 先把 i++ 放前面
int i = 0;
while (i < 5) {
    i++;
    if (i % 2 == 0) continue;
    cout << i;
}
嵌套循环：break 只跳最近一层

内层写 break，只跳出内层，外层照常继续。想一次跳出多层要靠标志变量。

for (int i = 1; i <= 3; i++) {
    for (int j = 1; j <= 3; j++) {
        if (j == 2) break;  // 只跳出内层
        cout << i << j << " ";  // 11 21 31
    }
}
break 经典用法：判断质数

从 2 试到 √n，找到因子就 break，不用再试，省时间。

int isPrime = 1;
for (int d = 2; d * d <= n; d++) {
    if (n % d == 0) {
        isPrime = 0;
        break;      // 找到因子，不用试了
    }
}

// break 和 for：找到就停
#include <iostream>
using namespace std;

int main() {
    // 输出 1 到 4，i=5 时 break
    for (int i = 1; i <= 10; i++) {
        if (i == 5) break;
        cout << i << " ";   // 1 2 3 4
    }

    // 找第一个平方 > 50 的数
    for (int i = 1; i <= 100; i++) {
        if (i * i > 50) {
            cout << i;      // 8
            break;
        }
    }
    return 0;
}
// continue 和 for：过滤掉不要的
#include <iostream>
using namespace std;

int main() {
    // 只输出偶数
    for (int i = 1; i <= 10; i++) {
        if (i % 2 == 1) continue;  // 奇数跳过
        cout << i << " ";   // 2 4 6 8 10
    }

    // 跳过 3 的倍数再求和
    int sum = 0;
    for (int i = 1; i <= 20; i++) {
        if (i % 3 == 0) continue;
        sum += i;
    }
    return 0;
}
// break 和 while：读入直到 0
#include <iostream>
using namespace std;

int main() {
    int x, sum = 0;
    while (cin >> x) {
        if (x == 0) break;   // 读到 0 就停
        sum += x;
    }
    cout << sum << endl;

    // 用 break 退出 while(true)
    int n = 1;
    while (true) {
        if (n * n > 100) break;
        n++;
    }
    return 0;
}
// continue 和 while：先更新变量，再 continue
#include <iostream>
using namespace std;

int main() {
    int i = 0;
    while (i < 10) {
        i++;                        // 先更新
        if (i % 2 == 1) continue;  // 跳过奇数
        cout << i << " ";           // 2 4 6 8 10
    }
    return 0;
}

// ❌ 若先 if(i%2==1) continue; 再 i++，
//    continue 后永远不 i++，条件不变 → 死循环！
// 判断质数：试到 √n，找到因子就 break
#include <iostream>
using namespace std;

int main() {
    int n;
    cin >> n;

    int isPrime = 1;
    for (int d = 2; d * d <= n; d++) {
        if (n % d == 0) {
            isPrime = 0;
            break;          // 找到因子，不用再试
        }
    }
    if (n < 2) isPrime = 0;

    if (isPrime) cout << "是质数" << endl;
    else cout << "不是质数" << endl;
    return 0;
}

💡 小贴士

  • break = 彻底退出：整个循环立刻结束；continue = 跳过本次：剩下代码不跑，直接下一轮
  • for 里 continue 会去更新部分：i++ 照常执行；while 里 continue 直接回条件判断
  • while + continue 陷阱：一定要在 continue 之前更新变量（如 i++），否则会死循环
  • break 只跳最近一层：嵌套循环里内层 break 不影响外层
  • 「找到了就停」用 break：找答案、退出 while(true)、读到 0 为止
  • 「这些不要」用 continue：跳过奇数、跳过 3 的倍数、过滤数据
  • 判断质数套路：从 2 试到 d * d <= n，找到因子就 break
