每一步都选当前看起来最好的，最后得到整体最优

1贪心的想法

每步取局部最优

不回头看，只在当前局面里挑一个最有利的。

什么时候能用

要能证明「局部最优能推成全局最优」，否则会出错。

步骤很短

排序 + 一次遍历，往往就能解决。

📌例子：找零钱
// 面额 50 20 10 5 1，问最少几张
int money = n;
int a[5] = {50, 20, 10, 5, 1};
int cnt = 0;
for (int i = 0; i < 5; i++) {
    cnt += money / a[i];
    money %= a[i];
}

⚠ 这个贪心对「50 20 10 5 1」成立，但如果面额是「1 3 4」找 6 元，贪心会拿 4+1+1（3 张），而最优是 3+3（2 张）——所以要看题目面额。

2贪心的常见套路

📌三步走

① 把物品按某个规则排序 → ② 从前往后遍历 → ③ 能拿就拿，拿不下就跳过

// 例：最多能装多少件（每件重量 w[i]，背包容量 C）
sort(w, w + n);              // 先挑轻的
int sum = 0, cnt = 0;
for (int i = 0; i < n; i++) {
    if (sum + w[i] <= C) { sum += w[i]; cnt++; }
    else break;
}

6小贴士

💡 小贴士

  • 贪心前先确认题目能不能贪（面额是否规整这类）。
  • 大多数贪心题第一步都是排序。
  • 排序规则要贴着题目要求写。
  • 贪心写完，最好用小数据验证一下。
  • 贪心不是万能的，拿不准就想想有没有反例。
