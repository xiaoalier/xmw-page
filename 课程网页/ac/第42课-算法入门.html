什么是算法、怎么衡量快慢（时间复杂度）

1算法和它的「快慢」

算法 = 解题步骤

把一个问题拆成有限步、每步都明确、最后一定结束的步骤，就是算法。

衡量标准：时间复杂度

看「运算次数随数据规模 n 怎么增长」，常见有 O(n)、O(n log n)、O(n²)。

为什么要管它

同样是正确答案，O(n²) 在 n 大时会超时，O(n log n) 却能过。

📌一句话判断

一层 for 循环 = O(n)；两层嵌套 = O(n²)；sort = O(n log n)。

2常见复杂度的差距

📌n = 100000 时的大致运算次数
O(n)        10 万次        —— 一层循环
O(n log n)  约 170 万次    —— sort
O(n²)       100 亿次       —— 两层嵌套（基本必超时）

⚠ 一般评测机 1 秒能做约 1 亿次简单运算，超过就危险。

6小贴士

💡 小贴士

  • 先估 n 有多大，再决定能不能用两层循环。
  • n ≤ 1e5 时，O(n log n) 一般没问题，O(n²) 会超时。
  • 能一层循环解决就别写两层。
  • sort 是 O(n log n)，可以放心用。
  • 复杂度是估算，常数大小也要看，但先看数量级。
