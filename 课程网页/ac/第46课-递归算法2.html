递归的常见应用：斐波那契、汉诺塔，以及重复计算的问题

1递归的两个经典模型

斐波那契

f(n) = f(n-1) + f(n-2)，终止条件 f(1)=1、f(2)=1。一个问题拆成两个更小的同类问题。

汉诺塔

把 n 个盘子从 A 移到 C：先把 n-1 个移到 B，再移最大的，再把 n-1 个移到 C。

共同点

都是「把 n 的问题，变成 n-1 的问题 + 一步操作」。

📌两类递归的区别

阶乘是一条路往下走；斐波那契会分叉成两条路，所以会重复计算——这就是后面要用记忆化的原因。

2重复计算的问题

📌f(5) 里 f(3) 被算了两次
f(5) = f(4) + f(3)
f(4) = f(3) + f(2)      ← 这里的 f(3) 又要重算一遍
f(3) = f(2) + f(1)

n 一大，重复计算会指数级增长（f(40) 就要算上亿次）。⚠ 记住这个现象：分叉递归要小心性能。

6小贴士

💡 小贴士

  • 斐波那契记住：f(n)=f(n-1)+f(n-2)，前两项是 1。
  • 汉诺塔记住三步：移走 n-1、移最大的、再移回来。
  • 分叉递归重复计算多，n 大时要换思路。
  • 汉诺塔步数公式是 2^n - 1。
  • 递归求 gcd 用辗转相除法，终止条件是 b == 0。
