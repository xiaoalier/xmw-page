1多分支：if / else if / else

是什么

不再是二选一，而是从好几条路里挑一条。从上往下一条条判断，第一条成立的就执行。

怎么用

if (条件1) { } else if (条件2) { } else { }，中间可以接好多条 else if。

顺序很重要

判断从上往下走，一旦某条成立，后面的就不看了。所以范围判断要从特殊到一般。

🪜成绩分档：把条件排好，一次只走一条
int score = 85;
if (score >= 90) {
    cout << "优秀" << endl;
} else if (score >= 80) {
    cout << "良好" << endl;   // 85 命中这里
} else if (score >= 60) {
    cout << "及格" << endl;
} else {
    cout << "不及格" << endl;
}
// 输出：良好

⚠ 易错：如果把 score >= 60 写在最前面，85 会先命中它，永远到不了"良好"。范围要从大到小排。

2switch-case：等值匹配的好帮手

是什么

当判断是"等于某一个值"时，switch 比一堆 else if 更整齐。

怎么用

switch (表达式) { case 值: ...; break; default: ...; }，每个 case 后通常要加 break;。

break 作用

break 表示"跳出 switch"。没有它，程序会继续往下穿透执行后面的 case。

🎯没有 break 会"穿透"，把后面的语句也执行了
// ❌ 忘记 break：命中 case 2 后会继续执行 case 3、case 4……
switch (n) {
    case 1: cout << "A";      // 少了 break
    case 2: cout << "B";      // 少了 break
    case 3: cout << "C"; break;
    default: cout << "D";
}

// ✅ 正确：每个 case 后加 break
switch (n) {
    case 1: cout << "A"; break;
    case 2: cout << "B"; break;
    case 3: cout << "C"; break;
    default: cout << "D";
}

💡 default 表示"都不匹配时走这里"，位置可以放最后。switch 里的值要用 int 或 char 这类能比较相等的类型。

3字符型 char：存一个字符

怎么定义

char c = 'A';，字符要用英文单引号括起来，和字符串的双引号不一样。

本质是数字

char 里存的是字符对应的 ASCII 码。比如 'A' 是 65，'a' 是 97，'0' 是 48。

常见用法

大小写转换、密码翻译、按字符判断类型，switch 也常用来匹配字符。

🔤字符可以当数字运算，也可以直接比较
char c = 'a';
cout << c << endl;            // 输出 a
cout << (int)c << endl;      // 输出 97（ASCII 码）

char up = c - 32;          // 小写转大写：'a'(97)-32='A'(65)
cout << up << endl;          // 输出 A

switch (c) {
    case 'a': cout << "字母 a"; break;
    default: cout << "其他";
}

⚠ 易错：'A'（字符）和 "A"（字符串）不是一回事；65（整数）和 'A' 虽然数值相关，但类型不同。

// 根据成绩输出等级
#include <iostream>
using namespace std;

int main() {
    int score;
    cin >> score;
    if (score >= 90) {
        cout << "A" << endl;
    } else if (score >= 80) {
        cout << "B" << endl;
    } else if (score >= 60) {
        cout << "C" << endl;
    } else {
        cout << "D" << endl;
    }
    return 0;
}
// 输入 1~3，输出对应字母
int n;
cin >> n;
switch (n) {
    case 1:
        cout << "A" << endl;
        break;
    case 2:
        cout << "B" << endl;
        break;
    case 3:
        cout << "C" << endl;
        break;
    default:
        cout << "其他" << endl;
}
// 故意利用穿透：多个 case 共用一段代码
int month;
cin >> month;
switch (month) {
    case 1: case 3: case 5: case 7:
    case 8: case 10: case 12:
        cout << "31 天" << endl;
        break;
    case 4: case 6: case 9: case 11:
        cout << "30 天" << endl;
        break;
    default:
        cout << "2 月" << endl;
}

// ⚠ 忘记 break 时，命中的 case 会"穿透"执行下面的语句
// char 存一个字符，本质是 ASCII 码
char c = 'a';
cout << c << endl;              // a
cout << (int)c << endl;        // 97

// 小写字母转大写：小写比大写 ASCII 大 32
char upper = c - 32;
cout << upper << endl;          // A

// 用 switch 判断字符类型
char ch = '7';
switch (ch) {
    case 'a': case 'b': case 'c':
        cout << "小写字母" << endl; break;
    case '0': case '1': case '7':
        cout << "数字字符" << endl; break;
    default:
        cout << "其他" << endl;
}

💡 小贴士

  • 多分支顺序：范围判断要从大到小（或从小到大注意覆盖），先命中的先执行
  • switch 的 case 是等值判断：只能判断"等于某个常数"，不能写 case x > 5:
  • break 不能忘：少了 break 会穿透执行下面的 case；有时也会故意利用穿透来合并多个 case
  • default 兜底：都不匹配时走 default，位置一般放最后
  • char 用单引号：'A' 是字符，"A" 是字符串，两者不能混
  • ASCII 要记牢：'0'=48，'A'=65，'a'=97；小写比大写大 32
  • switch 只能配整数或字符，不能直接拿浮点数或字符串来 switch
