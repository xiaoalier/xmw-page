1二分答案的思路

不是找数组里的数

而是二分「答案的取值」：在答案范围里猜一个值，判断它行不行。

必须有单调性

比如「长度越大，能切出的段数越少」——这种就能二分。

套路固定

二分答案 + check 函数判断可行性。

📌模板
int l = 最小可能答案, r = 最大可能答案, ans = -1;
while (l <= r) {
    int mid = (l + r) / 2;
    if (check(mid)) {          // mid 可行
        ans = mid;
        l = mid + 1;           // 想更大（求最大可行值）
    } else {
        r = mid - 1;
    }
}

⚠ 求「最大可行值」就往大边收（l = mid + 1）；求「最小可行值」就往小边收（r = mid - 1）。方向搞反必错。

2例子：猜数字

📌1~100 里猜一个数，最多几次？
// 每次告诉你「大了 / 小了 / 对了」
int l = 1, r = 100, cnt = 0;
while (l <= r) {
    int mid = (l + r) / 2;
    cnt++;
    if (mid == target) break;
    else if (mid < target) l = mid + 1;
    else r = mid - 1;
}
// 最多 7 次（log2 100 ≈ 6.6）

6小贴士

💡 小贴士

  • 先判断答案有没有单调性，再考虑二分答案。
  • check 函数是核心，一定要写对。
  • 求最大值往大收，求最小值往小收。
  • 答案范围要给够（别把最优解排除在外）。
  • 二分答案不需要数组有序。
