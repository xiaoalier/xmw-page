第15课 · for循环和一维数组的应用

用 for 循环遍历一维数组：求和、统计、找最值

1为什么要用 for 遍历数组

数组下标从 0 开始

存了 n 个元素的数组，合法下标是 0 ~ n-1。第 1 个元素是 a[0]，不是 a[1]。

for 让下标依次变化

for(int i=0; i<n; i++) 会让 i 从 0 一路走到 n-1，正好把每个格子访问一遍。

下标和值同步

循环时 i 是"第几格"，a[i] 是"这一格里装的值"。两者一起变化。

🧩遍历数组的标准写法
int a[5] = {10, 20, 30, 40, 50};
int n = 5;                    // 一共有 5 个元素

for (int i = 0; i < n; i++) {
    cout << a[i] << endl;      // 依次输出 a[0]、a[1]……a[4]
}

⚠ 易错：循环条件写成 i <= n 就多访问了 a[n]，越界之后结果不受控。记住 i < n。

2遍历数组能做什么

求和

准备一个 sum = 0，每访问一个元素就 sum += a[i]，循环结束 sum 就是总和。

统计个数

满足条件就 cnt++。比如统计偶数个数：if (a[i] % 2 == 0) cnt++;

找最值

先把 max = a[0]，然后从第 2 个开始比，谁大就更新 max = a[i]。

🎯三种套路，核心都是"一个一个看过去"
// 求和
int sum = 0;
for (int i = 0; i < n; i++) sum += a[i];

// 统计偶数个数
int cnt = 0;
for (int i = 0; i < n; i++)
    if (a[i] % 2 == 0) cnt++;

// 找最大值
int mx = a[0];
for (int i = 1; i < n; i++)
    if (a[i] > mx) mx = a[i];

💡 找最大值从 i = 1 开始比就可以，因为 mx 一开始就是 a[0]，不用自己跟自己比。

// 用 for 把数组从头到尾输出一遍
#include <iostream>
using namespace std;

int main() {
    int n;
    cin >> n;
    int a[100];
    for (int i = 0; i < n; i++) cin >> a[i];

    for (int i = 0; i < n; i++) {
        cout << a[i] << " ";
    }
    return 0;
}
// 求和：sum 从 0 开始，每格累加
int sum = 0;
for (int i = 0; i < n; i++) {
    sum += a[i];
}
cout << sum << endl;

// 输入：5   1 2 3 4 5
// 输出：15
// 找最大值：mx 先等于第一个元素
int mx = a[0];
for (int i = 1; i < n; i++) {
    if (a[i] > mx) mx = a[i];
}
cout << "最大值是 " << mx << endl;

// 输入：6   4 8 15 16 23 42
// 输出：最大值是 42
// 统计偶数个数：满足条件就 +1
int cnt = 0;
for (int i = 0; i < n; i++) {
    if (a[i] % 2 == 0) cnt++;
}
cout << "偶数有 " << cnt << " 个" << endl;

// 输入：6   4 8 15 16 23 42
// 输出：偶数有 4 个
// ❌ 错误 1：循环多跑一格，访问 a[n] 越界
for (int i = 0; i <= n; i++)   // i 会等于 n，越界！

// ✅ 正确：i < n
for (int i = 0; i < n; i++)

// ❌ 错误 2：求和变量没初始化
int sum;                 // 里面是随机值
for (...) sum += a[i];   // 结果会错

// ✅ 正确：sum 初始化为 0
int sum = 0;

💡 小贴士

  • 下标从 0 开始：n 个元素，合法下标是 0 ~ n-1，循环写 i < n。
  • 别越界：访问 a[n] 属于越界，结果不可控，一定要避免。
  • 累加先清零：求和/计数的变量，定义时就写成 = 0。
  • 找最大值先拿第一格：mx = a[0]，再从 i = 1 开始比较。
  • i 是下标，a[i] 是值：循环里两者一起变，看清楚谁是谁。
  • 输入数组也常用 for：for (i=0; i<n; i++) cin >> a[i];
