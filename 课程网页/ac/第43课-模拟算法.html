1模拟：把题面翻译成代码

没有花哨公式

模拟题不靠推导，靠「按题目描述的规则，一步步执行」。

关键是顺序

先做什么、后做什么，顺序错了结果就错。

边界要全

第 1 步、最后一步、没数据时怎么办，都要想到。

📌做模拟题的四个步骤

① 读题，把规则用一句话写下来 → ② 想清楚要用哪些变量 → ③ 按顺序写循环 → ④ 拿样例手推一遍。

2例子：机器人走格子

📌题目
起点 (0,0)，给一串指令：
  U 上（y+1）  D 下（y-1）  L 左（x-1）  R 右（x+1）
其他字符忽略。输出最后的坐标。
int x = 0, y = 0;
for (int i = 0; i < s.size(); i++) {
    if (s[i] == 'U') y++;
    else if (s[i] == 'D') y--;
    else if (s[i] == 'L') x--;
    else if (s[i] == 'R') x++;
}
cout << x << " " << y;

⚠ 用 string 存指令时，`s.size()` 是长度；用 char 数组记得 `\0` 结尾。

6小贴士

💡 小贴士

  • 先把规则写成一句人话，再翻译成代码。
  • 顺序很重要：先判断再移动，还是先移动再判断，要按题来。
  • 边界情况（第一步、最后一步、空输入）单独想一遍。
  • 用样例手推，比盯着代码看更容易发现问题。
  • 模拟题通常不难，但很考验细心。
