第33课 · 冒泡排序与插入排序

两种最经典的排序：一个靠「交换」，一个靠「插入」

1两种排序的原理

冒泡排序

从头到尾挨着比较相邻的两个数，左边比右边大就交换。这样每一轮都会把当前最大的数"冒"到后面去。n 个数最多做 n-1 轮。

插入排序

像整理手里的扑克牌：把第 i 个数取出，在前 i-1 个已排好的数里从后往前找位置，比它大的数整体后移，最后插进空位。

共同点

都是双重循环、时间复杂度 O(n²)、都是稳定排序（相等元素先后不改变）。适合数据量不大的场景。

🧩核心代码一眼看懂
// 冒泡：相邻比较，大的往后交换
for (int i = 0; i < n - 1; i++)
    for (int j = 0; j < n - 1 - i; j++)
        if (a[j] > a[j + 1]) swap(a[j], a[j + 1]);

// 插入：取出 key，前面比它大的整体后移
for (int i = 1; i < n; i++) {
    int key = a[i], j = i - 1;
    while (j >= 0 && a[j] > key) { a[j + 1] = a[j]; j--; }
    a[j + 1] = key;
}

⚠️ 易错：冒泡内层循环边界是 j < n - 1 - i，因为后面 i 个数已经排好了，不用再比。写错容易越界访问 a[n]。

for (int i = 0; i < n - 1; i++) {
    for (int j = 0; j < n - 1 - i; j++) {
        if (a[j] > a[j + 1]) {
            swap(a[j], a[j + 1]);   // 左边大就交换
        }
    }
}
// 优化：某一轮没有发生任何交换，说明已经有序
for (int i = 0; i < n - 1; i++) {
    bool swapped = false;
    for (int j = 0; j < n - 1 - i; j++) {
        if (a[j] > a[j + 1]) {
            swap(a[j], a[j + 1]);
            swapped = true;
        }
    }
    if (!swapped) break;   // 提前结束
}
// 插入排序：把 a[i] 插进前面已排好序的部分
for (int i = 1; i < n; i++) {
    int key = a[i];       // 先取出来，位置会腾出来
    int j = i - 1;
    while (j >= 0 && a[j] > key) {
        a[j + 1] = a[j];    // 比 key 大的数往后挪
        j--;
    }
    a[j + 1] = key;       // 放进空位
}

💡 小贴士

  • 冒泡一句话：相邻比较，大的往右冒，每轮冒出一个最大值
  • 插入一句话：取出一个，前面对齐，比它大的往后挪
  • 内层边界记牢：冒泡是 j < n - 1 - i，越界常在这里出错
  • 插入先存 key：int key = a[i]; 否则原值被覆盖找不回来
  • 复杂度：两种都是 O(n²)，数据量大时用 sort 更快
  • 稳定性：冒泡和插入都是稳定排序，相等元素先后顺序不变
  • 小优化：冒泡一轮没交换就说明有序，可以 break 提前结束
