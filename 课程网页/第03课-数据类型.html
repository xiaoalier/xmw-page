1常见的数据类型

int（整型）

最常用的整数类型，占 4 字节，能存大约 ±21 亿。一般题目都先用它。

long long（长整型）

更大的整数类型，占 8 字节，能存到约 ±9.2×10¹⁸。数很大时要用它。

float / double（实数）

用来存小数。double 精度更高，写小数计算时常用 double。

📏各类型的大致范围（先有个印象）
类型占字节大致范围
int4-2,147,483,648 ~ 2,147,483,647（约 ±21 亿）
long long8约 -9.2×10¹⁸ ~ 9.2×10¹⁸
float4约 6~7 位有效数字
double8约 15~16 位有效数字

⚠ 易错：把超过范围的数存进 int 会「溢出」，结果变得很奇怪。数值可能超过 21 亿时，改用 long long。

2整数除法 vs 小数除法

🔀同样的算式，类型不同结果不同
// 都是整数 → 整数除法，小数被丢掉
int a = 5, b = 2;
cout << a / b << endl;              // 输出 2

// 只要有一个是小数 → 小数除法
cout << 5.0 / 2 << endl;           // 输出 2.5
cout << (double)a / b << endl;     // 输出 2.5（把 a 临时变成小数）

⚠ 易错：写求平均分、除法计算结果时，如果两个数都是整数，结果会「丢掉小数」。想要小数结果，可以写 1.0 * a / b 或 (double)a / b；% 两边只能是整数。

#include <iostream>
using namespace std;

int main() {
    int a = 5, b = 2;
    cout << a / b << endl;           // 2（整数除法）

    return 0;
}
// 求三门课的平均分（要小数）
#include <iostream>
using namespace std;

int main() {
    int a = 90, b = 80, c = 71;
    double avg = (a + b + c) / 3.0;  // 除以 3.0 保证小数除法
    cout << avg << endl;
    return 0;
}

// 输出：80.3333
// 隐式转换与强制转换
#include <iostream>
using namespace std;

int main() {
    int n = 100;
    long long big = n;       // 隐式：小类型 → 大类型，安全
    double d = 5;             // 隐式：整数 5 → 5.0
    int y = (int)3.9;        // 强制：截断小数，y = 3
    cout << d << " " << y << endl;
    return 0;
}

// 输出：5 3
// ❌ 全是整数，得到整数结果
int a = 90, b = 80, c = 71;
cout << (a + b + c) / 3 << endl;     // 241 / 3 = 80（丢了小数）
cout << (a + b + c) / 3.0 << endl;   // 80.3333（正确）

// ❌ int 装不下太大的数（溢出）
int big = 2100000000 + 2100000000;   // 超过 int 范围，结果错误

// ✅ 用 long long
long long ok = 2100000000LL + 2100000000LL;

💡 小贴士

  • 整数先用 int：超过约 21 亿再用 long long。
  • 小数用 double：需要小数运算时，double 比 float 更稳。
  • 除法想得到小数：让其中一个数变成小数，例如 1.0 * a / b 或 (double)a / b。
  • 取余只吃整数：% 两边都必须是整数。
  • 小类型可以变大类型：int → long long、int → double 是安全的。
  • 大变小要小心：(int)3.9 会直接截断成 3，不是四舍五入。
