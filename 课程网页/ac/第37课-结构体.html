第37课 · 结构体

把一组的几个信息打包成一个整体

1为什么需要结构体

以前：一堆散变量

一个学生要存学号、姓名、成绩，得写 3 个变量；10 个学生就要 30 个变量，很难一起管理。

现在：打包成一个

结构体把「属于同一个对象的几种信息」打包成一个新类型，一个变量就能装下整套信息。

用起来和普通变量一样

定义好结构体后，可以像 int 一样声明变量、放进数组、当函数参数。

📌一句话理解

结构体 = 自己造一个类型。比如造一个「学生」类型，里面装着学号、姓名、成绩。

2结构体怎么定义、怎么用

📌定义格式
struct Student {      // 定义一个叫 Student 的结构体
    int id;           // 学号
    string name;      // 姓名
    int score;        // 成绩
};                    // ⚠ 这里的分号不能少

成员可以是 int、double、char、string，也可以是数组。⚠ 结尾的 分号是最容易漏的。

📌访问成员：用点 .
Student a;              // 声明一个学生
a.id = 1001;            // 给成员赋值
a.name = "小明";
a.score = 95;

cout << a.name << " " << a.score;   // 访问成员

6小贴士

💡 小贴士

  • 结构体定义结尾的分号最容易漏，写完先检查这一处。
  • 成员名在同一结构体里不能重复。
  • 结构体可以嵌套（结构体里再有结构体），也可以放进数组。
  • 结构体整体不能直接用 == 比较，要逐个成员比。
  • 给结构体数组读数据，用 for 循环配合 s[i].成员 最稳。
