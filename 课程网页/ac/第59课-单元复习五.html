递推、贪心、二分、前缀和、筛法、高精度：第五单元总复习

1第五单元知识地图

递推与贪心

递推是从小到大填表；贪心是每步取最优（要能证明）。

二分

二分查找要有序；二分答案要有单调性，配 check 函数。

前缀和 / 差分 / 筛法 / 高精度

前缀和把区间和变 O(1)；差分把区间修改变 O(1)；筛法一次求质数；高精度按位模拟。

📌怎么选方法

多次问区间和 → 前缀和；多次区间加 → 差分；求 n 内质数 → 筛法；答案有单调性 → 二分答案；数字超大 → 高精度。

2高频套路

📌五个模板，考前手写一遍
① 递推：f[1]、f[2] 给初值 → for i=3..n 推
② 贪心：sort → 一次遍历
③ 二分：l=0,r=n-1 → while(l<=r) → 收缩
④ 前缀和：s[i]=s[i-1]+a[i] → 区间和 s[r]-s[l-1]
⑤ 筛法：全true → 划倍数（从 i*i 起）
