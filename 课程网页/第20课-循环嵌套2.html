1图形打印三件套

外层管行

外层循环决定画几行。第 i 行对应外层变量 i，从 1 数到最后一行。

内层管列

内层循环决定这一行画几个。想让每行个数跟着行号走，就把内层条件写成 j <= i。

换行放外层

一行画完用 cout << endl; 换行。这句话要写在内层循环外面、外层循环里面。

🎯三种最常见的图形怎么写
// ① 矩形：每行都画 cols 个
for (int i = 1; i <= rows; i++) {
    for (int j = 1; j <= cols; j++) cout << "*";
    cout << endl;
}

// ② 直角三角形：第 i 行画 i 个（跟着行号走）
for (int i = 1; i <= n; i++) {
    for (int j = 1; j <= i; j++) cout << "*";
    cout << endl;
}

// ③ 九九乘法表：也是 j <= i
for (int i = 1; i <= 9; i++) {
    for (int j = 1; j <= i; j++) cout << j << "x" << i << "=" << i * j << " ";
    cout << endl;
}

✅ 记住一句话：外层管行、内层管列，换行写在外层。想要「第几行画几个」，就让内层条件 j <= i。

// 矩形：外层管行，内层管列
#include <iostream>
using namespace std;

int main() {
    int rows = 3, cols = 5;

    for (int i = 1; i <= rows; i++) {      // 外层：3 行
        for (int j = 1; j <= cols; j++) {  // 内层：每行 5 个
            cout << "*";
        }
        cout << endl;                      // 一行画完换行
    }
    return 0;
}

// 输出：
// *****
// *****
// *****
// 直角三角形：第 i 行画 i 个 *
#include <iostream>
using namespace std;

int main() {
    int n = 5;

    for (int i = 1; i <= n; i++) {      // 外层：n 行
        for (int j = 1; j <= i; j++) {  // 内层：画 i 个（跟着行号走）
            cout << "*";
        }
        cout << endl;
    }
    return 0;
}

// 输出：
// *
// **
// ***
// ****
// *****
// 九九乘法表：外层管行，内层管列，只算 j <= i
#include <iostream>
using namespace std;

int main() {
    for (int i = 1; i <= 9; i++) {
        for (int j = 1; j <= i; j++) {
            cout << j << "x" << i << "=" << i * j << " ";
        }
        cout << endl;   // 一行打完换行（写在外层里）
    }
    return 0;
}

// 输出：
// 1x1=1
// 1x2=2 2x2=4
// 1x3=3 2x3=6 3x3=9
// ...
// ❌ 易错 1：换行写进了内层，每个 * 后都换行
for (int i = 1; i <= 3; i++)
    for (int j = 1; j <= 4; j++)
        cout << "*\n";      // 换行跑到内层里了

// ❌ 易错 2：画三角形时内层条件写成 j <= n，结果变成矩形
for (int i = 1; i <= n; i++) {
    for (int j = 1; j <= n; j++) cout << "*";  // 应该是 j <= i
    cout << endl;
}

// ✅ 正确：换行放外层，三角形用 j <= i
for (int i = 1; i <= n; i++) {
    for (int j = 1; j <= i; j++) cout << "*";
    cout << endl;
}

💡 小贴士

  • 外层管行、内层管列：画图形时，外层定几行，内层定每行几个。
  • 换行写在外层：cout << endl; 放在内层循环外面，一行才能只换一次。
  • 跟着行号走：画三角形时内层条件写 j <= i，第几行就画几个。
  • 矩形 vs 三角形：内层条件 j <= cols 出矩形；j <= i 出直角三角形。
  • 乘法表也是三角形：外层 i、内层 j，用 j <= i 就能只算不重复的部分。
  • 先数后写：写之前先想清楚「几行、每行几个、哪里换行」，再动手。
  • 缩进要清楚：内层比外层多缩进几格，结构一眼就能看出来。
