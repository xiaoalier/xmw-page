vector：不用提前确定长度的数组

1为什么需要动态数组

数组长度写死

int a[100] 只有 100 个位置，多了就放不下。

动态数组能自动扩容

需要更大时会重新申请一块更大的空间，把数据搬过去。

vector 就是它

C++ 的 vector 就是动态数组，用起来像数组一样方便。

📌基本用法
vector<int> v;          // 空数组
v.push_back(3);        // 末尾加一个
v.push_back(5);

cout << v.size();      // 长度
cout << v[0];          // 像数组一样访问
v.pop_back();          // 删末尾
v.clear();             // 清空

⚠ v[i] 不会自动检查越界，越界访问是未定义行为；想安全检查用 v.at(i)。

2扩容与遍历

📌扩容通常是「容量翻倍」
vector<int> v;
for (int i = 0; i < 10; i++) {
    v.push_back(i);
}
// 容量可能是 1→2→4→8→16，而不是每次 +1

// 三种遍历
for (int i = 0; i < v.size(); i++) cout << v[i];
for (int x : v) cout << x;
for (auto it = v.begin(); it != v.end(); ++it) cout << *it;

⚠ 扩容要搬数据，所以「知道大概多少个数」时可以先 `v.reserve(n)`。

6小贴士

💡 小贴士

  • vector 就是能自动变长的数组。
  • push_back 在末尾加，pop_back 删末尾。
  • v.size() 是无符号数，比较时注意。
  • 越界访问不报错但很危险。
  • 知道数量时先 reserve，能少搬几次数据。
