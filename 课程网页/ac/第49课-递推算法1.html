1递推和递归的区别

递归：从上往下

把大问题拆成小问题，一直拆到能直接算的那一层。

递推：从下往上

先算最小的情况，再用它推出更大的一层，一层层往上填表。

递推更安全

没有函数调用的层层压栈，速度快、也不会栈溢出。

📌同一件事的两种写法
// 递归版：f(n) = f(n-1) + f(n-2)
int f(int n) {
    if (n <= 2) return 1;
    return f(n - 1) + f(n - 2);
}

// 递推版：从 f(1)、f(2) 往上推
f[1] = 1; f[2] = 1;
for (int i = 3; i <= n; i++) f[i] = f[i-1] + f[i-2];

2递推三要素

📌写递推要想清楚三件事

① 状态：f[i] 表示什么（比如「爬到第 i 级的方法数」）
② 初值：最小几项直接给出来
③ 递推式：f[i] 和前面几项的关系

// 爬楼梯：每次 1 级或 2 级，问上 n 级有多少种走法
f[1] = 1;  f[2] = 2;
for (int i = 3; i <= n; i++) f[i] = f[i-1] + f[i-2];

6小贴士

💡 小贴士

  • 先写清楚 f[i] 代表什么，再动手。
  • 初值（前一两项）一定要给对。
  • 递推式里下标别写反。
  • 答案可能很大，用 long long。
  • 只依赖前几项时，可以用滚动变量省内存。
