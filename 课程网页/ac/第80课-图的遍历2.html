顺带求距离

dist[v] = dist[u] + 1，第一次访问就是最短。

📌代码
dist[s] = 0;
queue<int> q; q.push(s);

while (!q.empty()) {
    int u = q.front(); q.pop();
    for (int v : g[u]) {
        if (dist[v] != -1) continue;
        dist[v] = dist[u] + 1;
        q.push(v);
    }
}

⚠ dist 初值设 -1；入队同时设距离。

6小贴士

💡 小贴士

  • BFS 用队列，按距离从小到大。
  • dist 初值 -1，入队时赋值。
  • 分层输出先记队列长度。
  • 染色法可以判断二分图。
  • BFS 队列可能很大，注意内存。
