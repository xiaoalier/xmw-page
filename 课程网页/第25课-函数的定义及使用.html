1什么是函数

函数小助手

函数就是一段有名字、可重复使用的代码。把常用功能打包起来，需要时喊一声名字就能用。

定义 vs 调用

定义是"把做法写出来"；调用是"用它的名字让它做一次"。定义一次，可以调用很多次。

三段式

返回值类型 + 函数名 + (参数列表) + { 函数体 }。例：int add(int a, int b)。

易错对比
// 没有参数、也没有返回值的函数
#include <iostream>
using namespace std;

void sayHello() {
    cout << "Hello, C++!" << endl;
}

int main() {
    sayHello();   // 调用一次
    sayHello();   // 再调用一次
    return 0;
}
// 有参数、没有返回值（void）
#include <iostream>
using namespace std;

void printStars(int n) {
    for (int i = 0; i < n; i++) cout << "*";
    cout << endl;
}

int main() {
    printStars(5);   // 输出 *****
    return 0;
}
// 有参数、有返回值：求两个数的和
#include <iostream>
using namespace std;

int add(int a, int b) {
    return a + b;   // 把结果返回给调用处
}

int main() {
    int ans = add(3, 5);
    cout << ans << endl;   // 输出 8
    return 0;
}
// 函数定义在 main 后面时，要先把「声明」写在前面
#include <iostream>
using namespace std;

int add(int a, int b);   // 声明（原型），结尾有分号

int main() {
    cout << add(2, 6) << endl;   // 先调用也没问题
    return 0;
}

int add(int a, int b) {   // 真正的定义在这里
    return a + b;
}
// ❌ 错误 1：有返回值的函数忘了 return
int add(int a, int b) {
    int s = a + b;   // 算了却没 return，调用处拿不到结果
}

// ❌ 错误 2：调用时忘了写括号
add(3, 5);   // ✅ 正确
// add;      // ❌ 这只是提到函数名，不会执行

// ❌ 错误 3：返回值类型写成了 void 却想 return 数值
// void 类型的函数里尽量不要 return 一个值

// ✅ 正确写法
int add2(int a, int b) {
    return a + b;
}

💡 小贴士

  • 函数名后面一定要有括号：add(3, 5) 才是调用，add; 不会执行
  • 有返回值就要 return：返回值类型不是 void 的函数，执行到 return 会把结果交回调用处
  • void 表示没有返回值：只做事、不交回结果，函数里可以不写 return
  • 形参是"接货的盒子"：调用时实参的值会复制给形参，函数里用形参算
  • 先定义再调用：函数写在 main 后面时，要在 main 前面写一句声明，结尾带分号
  • 定义只需要写一次：写好一个函数，可以在程序里调用很多次，代码不重复
