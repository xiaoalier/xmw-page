二进制与十进制互转 · 左移右移 · 取某一位

1二进制 ↔ 十进制

二进制 → 十进制

把每一位乘以它所在位置的权（2 的次方），再全部相加。位数从右往左、从 0 开始数。

十进制 → 二进制

用 2 反复去除，记下每次的余数，直到商为 0，再把余数倒序读出来。

编程递推写法

从左到右扫描二进制位，ans = ans * 2 + 当前位，一遍就能转成十进制。

🔁两种方向各看一个例子
// 二进制 1011 转十进制（按权展开）
1011 = 1×2³ + 0×2² + 1×2¹ + 1×2⁰
     = 8 + 0 + 2 + 1
     = 11

// 十进制 13 转二进制（除 2 取余，倒序）
13 ÷ 2 = 6 余 1   ↑
 6 ÷ 2 = 3 余 0   ↑  从下往上读
 3 ÷ 2 = 1 余 1   ↑
 1 ÷ 2 = 0 余 1   ↑
结果：13 = 1101

// 编程递推：1011 -> 11
ans = 0
ans = 0*2 + 1 = 1
ans = 1*2 + 0 = 2
ans = 2*2 + 1 = 5
ans = 5*2 + 1 = 11

⚠ 易错：权从 0 开始数，不是从 1；除 2 取余的余数要倒序排，别按先后顺序抄。

2位运算的"妙用"

左移当乘 2

n << k 相当于 n × 2^k。左移 1 位就是翻一倍。

右移当整除 2

非负整数 n >> k 相当于 n 整除 2^k，向下取整。

取某一位

(n >> k) & 1 就能取出 n 的第 k 位，结果是 0 或 1。

🧠例子里体会一下（n = 13，二进制 1101）
13 << 1 = 26      // 13 × 2
13 >> 1 = 6       // 13 整除 2
13 << 2 = 52      // 13 × 4
13 >> 2 = 3       // 13 整除 4

// 13 的二进制 1101，取各位：
第 0 位 (13 >> 0) & 1 = 1
第 1 位 (13 >> 1) & 1 = 0
第 2 位 (13 >> 2) & 1 = 1
第 3 位 (13 >> 3) & 1 = 1

// 判断奇偶：13 & 1 = 1，是奇数

💡 用位运算能省时间，也常用于"状态压缩""开关标记"这类题目。

// 除 2 取余，余数倒序输出
#include <iostream>
using namespace std;

int main() {
    int n;
    cin >> n;
    if (n == 0) { cout << 0; return 0; }
    int ans[40], cnt = 0;
    while (n > 0) {
        ans[cnt++] = n % 2;   // 取余
        n = n / 2;              // 除以 2
    }
    for (int i = cnt - 1; i >= 0; i--)
        cout << ans[i];          // 倒序输出
    return 0;
}

💡 小贴士

  • 二 → 十：按权展开，每位乘 2 的次方再相加，权从 0 开始。
  • 十 → 二：除 2 取余，商到 0 为止，余数倒序读。
  • 递推好写法：ans = ans * 2 + 当前位，从左往右一遍搞定。
  • 左移乘、右移除：n << k 是乘 2^k，n >> k 是整除 2^k。
  • 取某一位：(n >> k) & 1 得到第 k 位是 0 还是 1。
  • 判断奇偶：n & 1 为 1 是奇数，为 0 是偶数。
  • 0 要单独处理：十进制 0 转二进制就是 0。
